# Stage-II Layer B ↔ Layer C Mechanism Synthesis

## Scope

This comparison covers the **80 Layer-C-eligible cells** from G2–G5. Layer B remains the sealed **monitor-blind within-study partial-evidence semantic reference** over all 84 natural trajectories; Layer C is the sealed **GPT-5.6 Sol full-context process-mechanism reconstruction** over the 80 cells with adequate process surfaces. The four Layer-C boundary exclusions are not imputed.

Layer B and Layer C therefore answer different questions. Layer B asks what structural/semantic signatures are supportable from the frozen audit surface available to the independent blind reviewer. Layer C asks whether the complete process establishes the source → carrier → read/adoption → semantic transformation → decision/action → consequence relations required for C, P or R permission penetration.

## Aggregate comparison

Layer B has only **1/80 full-coverage cell** in the compared population; **79/80 are partial or evidence-limited**. It records 29 explicit positive C dimensions, 38 P and 24 R. Layer C supports or retains as candidate 13 C, 14 P and 13 R.

These totals should not be interpreted as an accuracy contest. Full-context reconstruction **recovers** positive dimensions not positively established by Layer B in **6 C, 6 P and 10 R** cases. Conversely, Layer-B structural positives are **not sustained under Layer-C full-process CPR criteria** in **22 C, 30 P and 21 R** cases.

The asymmetry is methodologically useful: partial evidence is broad enough to surface many structural candidates, while full-process evidence is required to decide whether those structures actually acquire semantic, execution or temporal permission.

## Four recurrent B↔C deltas

### 1. Historical visibility is not yet R

Layer C most strongly adds depth in R. A partial audit can see old-version files, checkpoint availability, repeated review or memory recurrence without being able to prove that prior process state has regained current authority. The 10 Layer-C R recoveries occur when the full route shows exactly that authority relation—for example, a pre-update launcher still controlling the current runtime, or a retired MemoryBank state materially reappearing after cleanup.

This is why R must remain defined as **retrospective reauthorization into a later C/P effect**, not historical presence, rereading, recall or duration.

### 2. More roles are not yet P

Layer B frequently marks visible role or scope expansion as P candidate/support. Layer C removes many of those positives when the complete route shows that QA, security, backend or reviewer participation remains necessary to the user-authorized task and the realized mutation remains local.

The reverse also occurs: Layer C recovers P when the full route shows that old or transformed authority actually changes the present execution surface. Thus P is not message volume, role count or broad review. It is **collaboration/execution permission penetrating beyond the operative task boundary**.

### 3. Carrier change is not yet C

Layer B is sensitive to file/hash/carrier transformations. Layer C often rejects those as C when direct evidence remains intact and no unsupported descendant replaces it. But Layer C also recovers C that Layer B cannot see because semantic payloads are missing—for example, when a feature created during the run is later described as something that “already existed” and “required no changes.”

C therefore requires more than transformation: the descendant must acquire **operational semantic authority**.

### 4. Retrieval, persistent memory and compression are carriers, not automatic common pools

Layer B records many retrieval, historical-reentry, repeated-review and recursive-memory structures. Layer C shows that repeated RAG hits, MemoryBank recall or LongLLMLingua compression can remain mere availability. They become process-inertial only when downstream agents adopt or reauthorize them.

The strongest counterexample is the negative trio **X5-T1 / X6-T1 / X7-T1**: repeated retrieval, persistent recall and repeated compression are all visible, yet no CPR dimension is established. The decisive exception is **G5-X6-T3**, where a retired state physically reappears and regains current execution authority, producing R→P.

## System-level interpretation

**AutoGen (X1)** — Layer C mainly adds causal depth to R/P. Layer B can see transformations and broad structures, but the complete route shows that retained launcher authority is the mechanism causing current execution displacement.

**MetaGPT (X2)** — Layer B often sees role expansion or historical structure; Layer C frequently keeps those below P/R threshold while recovering Dynamic C in provenance loss.

**A2A (X3)** — Layer B and C align strongly on T2 scope expansion. Layer C adds the historical cause in some runs, converting visible expansion into an R→P mechanism.

**MCP (X4)** — Tool/role breadth often looks like P on partial surfaces. Full context shows when the material action surface remains authorized and instead reveals provenance C or a censored semantic descendant.

**RAG (X5)** — Retrieval availability is cleanly separated from adoption. X5-T2 demonstrates that a retrieval layer can coexist with recurrent provenance C and, in one trajectory, an open C+R+P structure.

**MemoryBank (X6)** — Persistent recall is not R. The decisive threshold is whether prior state regains current authority; G5-X6-T3 crosses that threshold, while stale recall in other runs does not.

**LongLLMLingua (X7)** — Compression repeatedly transforms context representation, but only one censored trajectory reaches candidate C→P. Most compression activity remains below the permission threshold.

## Interpretation boundary

This comparison does **not** label Layer B “wrong” or Layer C “ground truth.” Layer B is a deliberately monitor-blind, partial-surface reference; Layer C is a fuller mechanism reconstruction. The scientifically relevant result is how conclusions change when the evidence surface expands.

The next comparison therefore shifts from **B ↔ C** to **A ↔ C**: whether the prospectively frozen online monitor detected the mechanisms that Layer C can reconstruct, and—separately—whether it localized their source, carrier, consumer and decision link.
