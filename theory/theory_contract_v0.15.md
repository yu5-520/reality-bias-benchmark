## 1. Scientific principle

A stochastic multi-Agent system is studied at two different units:

1. domain-environment natural trajectory population — probability/distribution;
2. one already-realized source-bound trajectory — case structure/mechanism.

These units must not be collapsed by repeated fixed-parent sampling.

## 2. Realized-path principle

Once a natural trajectory is frozen, that realized process is scientific evidence in its own right.

A realized path does not need to be regenerated from the same frozen parent to exist as a structure.

Known realized semantic objects must not be reconstructed by stochastic replay when the frozen addressable structure already exists.

`stochastic replay != structural repair`

## 3. Canonical case matrix

For one qualified source-bound case:

```text
N0    frozen natural continuation
R5-I  one-shot semantic correction
R7-P  persistent semantic correction
R7-S  structured lineage repair
```

These are different intervention modes, not repeated samples of one intervention.

## 4. R5

R5 is a single-realization transient semantic probe.

Canonical evidence:

`N0 existing frozen natural continuation + exactly one new R5-I continuation`

R5-I applies the selected semantic/epistemic change once. For the current operator family this is one prompt-visible `fact -> unconfirmed` transition.

Forward invariants:

- natural control is the already-frozen N0 trajectory;
- no synthetic control continuation is created;
- no replicate is required;
- exactly one new provider trajectory is permitted per R5 case;
- fixed-parent repeats are supplementary only.

## 5. R6

R6 is passive.

It consumes N0 + R5-I frozen evidence and derives structure/semantic relations offline.

`R6_NEW_SUBJECT_RUNS = 0`

R6 does not use repeated sampling to decide whether an already-realized carrier/read/adoption/persistence relation exists.

## 6. R7

R7 is a two-intervention engineering experiment after lineage completeness.

Canonical arms:

### R7-P — Persistent Semantic Correction

The same semantic/epistemic correction used transiently in R5 is continuously exposed on relevant downstream turns within the declared horizon.

This tests persistent semantic control.

### R7-S — Structured Lineage Repair

An evidence-bound Semantic Lineage Package / RepairClosure is repaired structurally, with compatible state preserved and affected descendants selectively invalidated/recomputed.

This tests localized structural recovery.

Canonical geometry:

- one R7-P trajectory;
- one R7-S trajectory;
- zero new C1/R5 one-shot trajectories;
- zero canonical replicates.

R5-I is the transient-semantic reference and is not rerun inside R7.

- define domain occurrence;
- erase realized structure;
- gate R6;
- gate R7;
- define canonical R5;
- define canonical R7.
