# Reality Bias Research Program
## Theory Contract v0.14 — Domain Stochasticity and Realized Case Structure

Date: 2026-09-19  
Status: FORWARD / PROCESS REALITY v5.3  
Predecessor: `theory/theory_contract_v0.13.md`

## 1. Scientific object

Process Reality studies whether source epistemic state, semantic boundary and decision meaning remain faithful as information moves through stochastic multi-Agent systems and becomes reusable system reality.

Two scientific units are mandatory:

1. **Domain-environment trajectory population** — probability/distribution.
2. **Naturally realized source-bound case** — structure/mechanism.

## 2. Domain-level stochasticity

A probabilistic Agent system is not expected to reproduce one exact path from one fixed local state.

The probability object is environmental:

`P(phenomenon class | frozen domain environment)`

A domain environment freezes the protocol while allowing natural trajectory variation.

## 3. Dynamic formation

Formation remains dynamic across runs:

`source -> variable Agent path -> transformation -> support/pool -> descendants`

The exact Escape Structure, first support point and first pool-entry event may differ by trajectory.

This variability is part of the phenomenon, not automatically experimental noise.

## 4. Case-level structure

Once a qualifying case appears, its realized path is a structural object.

A case-level structural claim asks:

`what obtained status -> through what carrier -> read by whom -> adopted how -> constrained what -> persisted how`

A structure does not need high cross-run recurrence to exist as a realized structure.

## 5. Structural Support and shared reality

Structural Support, Stable Shared Information Pool, content addressing and Semantic Lineage Package retain their v0.13 meanings.

Shared addressability never implies epistemic validity.

## 6. System Inertia

System Inertia is supported at case level when evidence shows that a semantic descendant, constraint or action tendency continues to shape later process behavior after the relevant direct stimulus/challenge is no longer present.

Case-level inertia is not a prevalence estimate.

Domain-level inertia probability requires a natural trajectory denominator.

## 7. R5

R5 is a case-level minimal driver probe.

The one-shot `fact -> unconfirmed` operation is one probe family.

R5 does not re-estimate domain probability.

## 8. R6

R6 is passive by default.

It consumes frozen natural/R5 evidence and derives:

- source/root;
- transformation;
- carrier/support;
- pool/exposure;
- downstream read;
- semantic adoption;
- decision/action dependence;
- post-stimulus persistence;
- affected semantic closure;
- candidate intervention surface.

No new provider run is required merely to enter R6.

## 9. Fixed-parent local sensitivity

Repeated fixed-parent trials may be retained only as supplementary local conditional sensitivity.

They answer a narrow local recurrence question.

They do not define:

- domain prevalence;
- whether an already-recorded carrier existed;
- whether downstream Agents read/adopted that carrier;
- whether R6 may analyze the realized path.

## 10. R7 / R8 boundary

R7 entry depends on case-level affected-lineage completeness and repairability, not fixed-parent recurrence frequency.

R8 remains semantic/CPR interpretation over frozen evidence.

## 11. Required claim labels

Forward reports distinguish:

- `DOMAIN_LEVEL_OCCURRENCE`;
- `CASE_LEVEL_STRUCTURE`;
- `CASE_LEVEL_SYSTEM_INERTIA`;
- `SUPPLEMENTARY_LOCAL_CONDITIONAL_SENSITIVITY`.

These labels must not be used interchangeably.

## 12. Falsifiability

The theory is weakened if:

- domain probability is estimated without a natural trajectory denominator;
- case-level structure cannot be bound to raw evidence;
- semantic adoption is inferred from reachability alone;
- fixed-parent non-reproduction is used to erase an observed case-level structure;
- R6 requires an unstated new subject experiment;
- R7 entry is made contingent on exact-phenotype recurrence rather than lineage completeness.

## 13. Frozen evidence compatibility

All previous raw traces, hashes and executed artifacts remain immutable.

v0.14 is an append-only forward interpretation correction.

## 14. Authorization

This contract authorizes no provider call, evaluator call, active repair or CPR adjudication.
