## 1. Scientific object

Process Reality studies whether source epistemic state, semantic boundary and decision meaning remain faithful as information moves through a multi-Agent process and becomes shared/reusable system reality.

## 2. Dynamic formation

The formation path is not assumed to be fixed across runs.

```text
Run A: source -> Agent B -> shared state
Run B: source -> Agent C -> Agent D -> shared state
Run C: source -> derived judgment -> shared state -> later Agent
```

Therefore the first support point, first pool-entry event and exact Escape Structure may differ by run.

They remain scientific observables when available, but are not universal engineering prerequisites.

## 3. Formation mechanism

Forward scientific chain remains:

`Multi-source conditions -> Unstable Information -> Escape Structure -> Semantic Transformation -> Structural Support -> Stable Shared Information Pool -> Semantic Descendants`

Escape Structure is a variable realized transmission structure, not a fixed workflow step.

## 4. Stable shared reality

Stable Shared Information Pool means system-addressable/reusable shared state.

It does not mean true or confirmed.

Later pool existence may be established even when the first pool-entry event is not localized.

## 5. Structural Repair Anchor

Engineering control may begin at a sufficiently exposed, machine-addressable and repair-efficient structural node.

`Repair Anchor != Semantic Origin`

`Repair Anchor != First Structural Support`

`Repair Anchor != First Pool Entry`

The anchor is chosen for control efficiency, not causal primacy.

## 6. Semantic-lineage scoped locality

Localized repair is defined by semantic scope.

A target repair may traverse the full temporal depth of its relevant lineage while excluding unrelated task semantics.

`local != shallow`

`local = complete relevant semantic lineage + minimal unrelated context`

## 7. Content addressing

The Repair Anchor provides an addressable entry point from which the system follows provenance and relation evidence to reconstruct the target Semantic Lineage Closure.

Content identity alone does not prove semantic adoption.

## 8. Completeness

A Repair Agent must not infer missing semantic history as fact.

Automatic repair requires a sufficient relevant-lineage completeness state.

If critical evidence is absent, the correct state is `LINEAGE_GAP`, not semantic completion.

## 9. Paper-layer separation

The first paper separates:

1. Theory/phenomenon experiments — formation and persistence.
2. Engineering/control experiments — addressability, completeness, repair scope and recovery.
3. Future discussion — portable Process Integrity infrastructure.

Scientific explanation and engineering control are related but distinct claims.
