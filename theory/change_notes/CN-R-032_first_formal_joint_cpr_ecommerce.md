# CN-R-032 — First formal joint C/P/R E-commerce experiment

**Status:** ACCEPTED BEFORE FORMAL SUBJECT COLLECTION.

## Decision

The next formal subject experiment uses one E-commerce Base condition and observes Completion, Perfection and Retrospective Reality Bias together on the same Free-Agent Arena traces.

C, P and R are dependent semantic outcomes to be adjudicated later. They are not separate subject arms, are not exposed to the subject Agents, and are not required to co-occur within any individual run.

The same frozen traces simultaneously support:

- R2 event-layer review of C/P/R and realized I/V/T actions;
- R3 exposure / inheritance relation analysis;
- R4 structural-feedback measurement and later semantic loop review.

## First formal batch

The first formal discovery batch is fixed at **3 E-commerce Base runs** under `R2-FREE-AGENT-ARENA-v0.3.2` with the existing 32-turn fixed observation horizon and normal invocation/queue safety caps.

This is a preregistered formal discovery batch, not a prevalence estimate and not a powered confirmatory sample. The N=3 choice is deliberately bounded because long Free-Agent traces can be expensive and semantic review is deferred.

All attempted runs are preserved under their objective status. A transport failure, censoring boundary, negative semantic result or inconvenient topology does not authorize subject regeneration.

## Review and measurement

No paid evaluator is called automatically. The formal workflow ends after:

`subject run → raw evidence freeze → integrity/objective statistics → R2/R3/R4 review-material export → PENDING_REVIEW`

Semantic review later records C/P/R and authorization separately. `NOT_ADJUDICATED` is not zero.

The experiment does not assume a universal C→I, P→V or R→T diagonal. It also does not interpret the Bias × Authority 3×3 table as evidence for a C→P→R temporal sequence.

## Base / K boundary

This batch is Base only. K=2 is a separate upper-bound experiment and is not activated by this Change Note.

A Base trace that naturally contains multiple structural feedback rounds remains a Base trace. It is not retrospectively converted into K-controlled evidence.

The existing K=2 runtime remains engineering-validated but not part of this first formal Base batch. K=4 remains unavailable until a future real K=2 batch passes its deferred semantic gate.

## Formal-data boundary

Only data collected after this Change Note and `docs/R234_ecommerce_formal_joint_cpr_v1_protocol.md` are frozen, through the dedicated formal workflow, belong to the first formal discovery batch.

Historical pilot, smoke, failed-infrastructure and scripted-provider records remain historical evidence and are never silently reclassified as formal observations.
