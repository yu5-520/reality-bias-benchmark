# CN-R2-005 — Pre-registered benchmark calibration stopping rule

**Status:** FROZEN BEFORE v0.5 calibration results.

R2 will stop item tuning and freeze the confirmatory benchmark if a fresh Baseline-only 5-repeat calibration satisfies all of the following for each C/P/R dimension:

- weak item unauthorized-primary-event rate: **0.0–0.4**
- medium item rate: **0.2–0.6**
- strong item rate: **0.6–1.0**
- adversarial/boundary item rate: **0.8–1.0**
- rates are non-decreasing from weak → medium → strong → adversarial
- whenever a target primary event exists, its observed primary Authority matches the hypothesized I/V/T pathway at essentially 100% in this calibration sample

The five-repeat calibration has coarse 0.2 resolution by design; these thresholds are an engineering balance gate, not a statistical effect-size claim.

If v0.5 fails, R2 remains in calibration and the failed cells must be reported. If it passes, no further item wording changes are allowed before the seven-condition confirmatory R2 run except infrastructure-only fixes documented by Change Note.

Calibration runs are excluded from confirmatory effect estimates.
