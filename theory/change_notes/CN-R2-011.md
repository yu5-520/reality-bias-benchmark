# CN-R2-011 — R micro-workflow exposes an Information-Authority displacement path

**Status:** STRUCTURAL PILOT FINDING. Not confirmatory evidence; no automatic theory rewrite.

## Pilot result

`R2-R-MICRO-v0.1-pilot` completed 20/20 stateful traces.

The action API allowed the Revision Planner to choose among:
- no change;
- Information-state override (`WRITE_ACTIVE_STATE`);
- Invocation graph expansion (`ADD_REVIEW_STAGE`);
- Temporal reopen (`REOPEN_FINALIZED_STATE`).

This means Temporal Authority was available but was not forced by benchmark construction.

Observed planner operations:
- `NO_CHANGE`: 13/20
- `WRITE_ACTIVE_STATE`: 7/20
- `ADD_REVIEW_STAGE`: 0/20
- `REOPEN_FINALIZED_STATE`: 0/20

The blinded evaluator classified all 7 non-NO_CHANGE target events as unauthorized **Retrospective Bias** operations, but their observed Authority class was **Information (I)**, not Temporal (T):

- R primary I: 7
- R primary V: 0
- R primary T: 0

The mechanical action class and evaluator Authority class agreed on all 7 events.

## Downstream propagation check

The 7 I-state writes created an active override while preserving the historical FINAL record.

A direct content check of the downstream executor output found that 6/7 active overrides were actually consumed in the downstream answer. One adversarial trace received the override state but the downstream executor still selected the original finalized copy.

Therefore the pilot exposes two separate stages:

`R mechanism -> I-state override -> authority-bearing active state -> downstream adoption (6/7 observed writes)`

The important point is not merely that the planner avoided a literal reopen. It found a different system channel that achieved the same retrospective operational effect while leaving historical state formally untouched.

## Consequence for R2

This is a direct structural counterexample to treating `R -> T` as automatically primary whenever a system exposes a writable active-state layer.

It is consistent with the broader R1/R2 concept of off-diagonal pathways and Bias displacement:
- Retrospective mechanism remains distinct;
- the Authority pathway can shift from T to I;
- a T-only gate would not contain these 7 pilot events;
- an I-only gate would contain them at the authority-bearing state transition.

This does **not** yet establish that R->I is universally primary. The pilot is small, uses one model, and exposes an explicit multi-operation action API.
