# CN-R-066 — R8 Trajectory-First Dynamic Semantic Audit Chain Repair

Date: 2026-09-20
Status: ACCEPTED / FORWARD CANONICAL METHOD CHANGE

## Problem

The previous R8 chain correctly preserved structural/semantic evidence boundaries but still used a window-first workflow:

`structural selector -> semantic window -> C/P/R adjudication`.

That workflow under-represented the actual research object: dynamic semantic evolution across interacting Agents.

It also created three concrete risks:

1. Dynamic C could be reduced to source/status continuity and miss functional semantic carrier substitution.
2. Dynamic P could be reduced to collaboration structure and miss goal/result/process authorization drift.
3. Dynamic R could be reduced to reopen markers or selected modern R7 traces and miss full retrospective/censored continuations.

## Decision

R8 is changed to:

`complete frozen trajectory -> dynamic semantic reconstruction -> functional semantic episodes -> joint C/P/R adjudication -> coupling`.

Structural analysis remains upstream only as evidence indexing.

## C correction

The reviewer must follow both propositional and functional semantic lineage.

The previously frozen two C-positive cases remain high-confidence narrow-source anchors.

They do not define the total number of Dynamic C episodes.

## P correction

Every P audit must compare:

`Original Goal <-> Authorized Boundary <-> Realized Process Scope <-> Final Result / Actual Changes`.

Process-side and result-side P are both mandatory.

## R correction

Every R audit must follow the full retrospective continuation.

Historical R7 trajectories remain valid scientific evidence even if a later engineering operator superseded them.

The formal R7 v0.3 budget-censored C3 trace:

`r7:prospective-ecommerce-natural-0001:triad:0001:c3_alr`

is mandatory re-audit material.

## Censor correction

An active chain stopped by a fixed runtime/observation boundary is not a negative outcome beyond the boundary.

Known first-round natural traces include 42 `turn_budget_exhausted` trajectories requiring censor-aware review.
