## Adapter hardening

The DeepSeek adapter now:
- detects top-level application `error` payloads even when HTTP transport succeeds;
- fails fast instead of passing error JSON into the model-response scorer;
- records provider error details in job logs without exposing the API key;
- uses shorter transport timeouts/retries so a provider outage cannot silently consume a two-hour experiment window.

## Recovery protocol

1. Run a full-path smoke test on one C, one P and one R Baseline item.
2. Only if all three succeed, launch the 60-cell v0.5 calibration.
3. Apply the already pre-registered CN-R2-005 calibration gate unchanged.
4. If the gate passes, freeze the benchmark and enter the 252-cell confirmatory R2 matrix.

The failed v0.5 attempt is never merged with the fresh recovery run.
