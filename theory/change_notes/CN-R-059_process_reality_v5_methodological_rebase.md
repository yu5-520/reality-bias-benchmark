# CN-R-059 — Process Reality v5 Methodological Rebase

Date: 2026-09-18  
Status: FORWARD THEORY / EXPERIMENT-CHAIN MIGRATION / NO SCIENTIFIC RUN AUTHORIZATION

## Trigger

R2-R6 evidence and retrospective semantic audit no longer support a theory in which a latent Escape Propensity simply realizes as a discrete Jump that then creates downstream inheritance.

The observed formation history can begin before the selected J0 anchor. Information may be preliminary, local, conditional or otherwise epistemically unstable, then be transformed across Agent-to-Agent transmission, shared state and downstream decision use before a later structural anchor becomes easy to observe.

The first-paper object is therefore widened from Jump-centered inertia to process-level information-state and structural-support migration.

## Decision

Forward Process Reality v5 uses the following theory chain:

\`\`\`text
multi-source information / pressure / goal / boundary
  -> unstable information
  -> Agent-mediated transmission
  -> escape structure
  -> semantic transformation
  -> structural support
  -> stable shared information pool
  -> direct Agent consumption
  -> constraint / decision / action persistence
\`\`\`

Observation and control are separated from formation:

\`\`\`text
structural support
  -> structural pressure accumulation
  -> structural exposure
  -> scout
  -> trace upstream / downstream
  -> select intervention surface
  -> repair / recovery
\`\`\`

## Core corrections

1. Escape is not a special information item emitted by one Agent. Escape is a transmission-structure phenomenon.
2. Unstable information is not synonymous with false information.
3. Semantic genesis, structural support, stable-pool entry and structural exposure are distinct objects.
4. Historical J0 remains a frozen experimental identifier. It is not automatically semantic origin, first structural-support point or exposure anchor.
5. Detection surface, trace root and intervention surface are allowed to differ.
6. R5 forward scope expands to structural scouting plus driver discrimination. Historical one-shot authority withdrawal remains one implemented R5 probe family.
7. R6 forward scope expands from inertia-only identification to support/trace/control-surface identification.
8. R7 remains localized recovery but now consumes explicit support/pool/exposure/trace objects where available.

## Experimental-chain consequence

Future core experiments should prefer whole-process collection over mandatory repeated target-specific comparison stacks.

Historical S0-S4, R6-A/B/C/D, Jump recurrence and specificity artifacts remain immutable evidence and may be reused as optional robustness modules. They are not silently renamed or backdated.

Forward interpretation is versioned. Legacy identifiers are preserved as provenance.
