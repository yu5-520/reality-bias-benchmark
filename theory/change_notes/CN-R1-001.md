# Change Note CN-R1-001
## R1 stress-test patch to the frozen R0 theory contract

**Trigger:** R1 counterexamples P04, S01, and S05 reveal a false equivalence in the v0.1 decision rule.

## Problem

The frozen v0.1 contract used the shortcut:

- Information violation → primary C
- Invocation violation → primary P
- Temporal violation → primary R

This is too broad.

An Authority violation is **necessary for Reality Bias Realization**, but the Authority class alone is **not sufficient to identify the Reality Bias mechanism**.

Counterexamples:

- A wrong but already-authorized tool choice is a tool-use error, not Perfection Bias.
- A prompt-injection-induced unauthorized action can violate Invocation Authority without being completeness-driven expansion.
- Mechanical memory poisoning can create a bad authority-bearing state without model-originated probabilistic inference.

If unchanged, the theory would absorb too much of agent safety under C/P/R and lose discriminant validity.

## Accepted patch

### Patch A — Bias-Mechanism Sufficiency Rule

A realized event receives a C/P/R label only if **both** are true:

1. the corresponding Authority transition is invalid; and
2. the event independently satisfies the mechanism definition of that Bias.

Therefore:

- `I violation` is not automatically C;
- `V violation` is not automatically P;
- `T violation` is not automatically R.

Events may instead be labeled:

- `OTHER_AUTHORITY_VIOLATION`
- `EXTERNAL_STATE_POISONING`
- `OTHER_AGENT_ERROR`
- `OUT_OF_SCOPE`

### Patch B — Primary-label decision rule

Primary label is selected by the **earliest realized authority-violating event that also satisfies a Bias mechanism**, not merely the earliest Authority violation.

If an earlier Authority violation does not satisfy C/P/R, it remains a separate security/control failure and does not force a Reality Bias label.

### Patch C — External-origin boundary

Externally originated malicious or false content is not, by itself, Reality Bias.

It becomes relevant to Reality Bias only when the model performs a probabilistic promotion, interpretation, completion, expansion, or retrospective transition that satisfies the C/P/R mechanism and obtains system effect.

### Patch D — Generation threshold

Ordinary explicitly hypothetical reasoning is not Bias Generation.

Bias Generation requires a proposal/inference that is **beyond the authorized epistemic/action/temporal contract** or is being advanced toward an unauthorized promotion.

## Expected effect on previous labels

This patch narrows the taxonomy and should reduce false positives in:
- prompt-injection cases,
- ordinary tool mistakes,
- deterministic rollback/recovery,
- mechanical memory poisoning,
- repeated authorized calls,
- ordinary hypothetical reasoning.

The patch does **not** alter the primary C↔I, P↔V, R↔T hypotheses; it clarifies that these are mechanism-conditioned primary mappings.

## Decision

**ACCEPT**

Reason: without this patch, the taxonomy risks collapsing into a relabeling of generic authorization failures.

## Re-annotation requirement

All R1 cases were adjudicated under the patched rule.  
Before R2, any future imported V26/public traces must use the patched rule.
