# CN-R-062 — Dynamic CPR Permission-Penetration Semantic Rebase

Date: 2026-09-20
Status: ACCEPTED FOR FORWARD R8 PLANNING

## 1. Decision

Forward R8 theory is rebased from three primarily static semantic label definitions to a coupled dynamic model of Process Reality Permission Penetration.

The historical CPR contracts remain immutable and valid for their own evidence versions.

## 2. New mapping

- C: information permission penetration;
- P: collaboration/execution boundary permission penetration;
- R: temporal permission penetration.

These are dynamic and may overlap, alternate, induce and mutually maintain one another.

## 3. Reason

Completed R5-R7 evidence showed that one-shot challenge, recomputation, independent re-anchoring, descendant-lineage persistence, persistent correction and structural repair cannot be faithfully interpreted with surface labels alone.

The theory therefore separates:

- independent evidence from lineage-derived semantic support;
- propagation from permission penetration;
- process-side P from result-side P;
- lineage-preserving R from retrospective-generative R;
- normal recovery/re-anchoring from Reality Bias.

## 4. Shared pool

The shared pool is promoted to an explicit Shared Process-Reality Layer because it allows semantic descendants to be reused and transformed across Agents and across later retrospective windows.

## 5. R8 execution effect

R8 will reconstruct semantic events and permission-boundary changes from frozen evidence, then adjudicate coupling and freeze a new append-only interpretation layer.

No new subject run is required merely because the theory or reviewer set changes.

## 6. Non-retroactivity

Historical R8 v0.1/v0.2, CPR definition/adjudication contracts, reviewer outputs, R2-R7 traces, reports and manifests are not relabeled in place.

## 7. Authorization

This note authorizes no paid reviewer call, provider run or active intervention.
