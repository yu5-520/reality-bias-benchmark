docs/reports/2026-09-26/StageII_Child01_Native_Heterogeneous_Execution_and_Process_Reality_Report_v1.md

The report does not introduce a new experiment. It binds already-frozen 21-cell Stage-II evidence into the repository reporting grammar:

Frozen Evidence -> Complete Recorded Route -> Semantic Lineage Overlay -> Node/Edge Semantic Audit -> Realized Process Contrast -> Supporting Structural/Carrier Data -> Claim Boundary -> Provenance.

The methodological purpose is to establish, with independent child evidence, that:

1. heterogeneous native framework/protocol/capability execution is real;
2. AI coding acts on real isolated checkout state;
3. passive monitoring records without owning execution;
4. process differences remain scientifically visible even when a local functional objective is reached;
5. those differences are not framework rankings.

The report introduces no new subject/provider/evaluator call, no rerun, no repair, and no C3/C4 contrast.

A Stage-II-specific report evidence bundle v0.2 and Report Standard v1.10 are added because the historical v0.1 evidence-bundle schema is bound to the earlier three-domain R-series report standard and should not be force-fit onto the one-domain heterogeneous Stage-II design.

The forward invariant is:

**normalize evidence after native execution; do not normalize execution in order to make reporting easier.**

Child Report 01 is the empirical foundation for subsequent T2/T3 task-pressure and information-layer child reports.
