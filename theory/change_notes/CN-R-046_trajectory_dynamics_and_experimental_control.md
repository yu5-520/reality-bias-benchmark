# CN-R-046 — Trajectory Dynamics and Experimental Control Alignment

Date: 2026-09-16  
Status: ACCEPTED FOR FORWARD PLANNING  
Applies to: R Plan v3.2 / Theory Contract v0.3 / Trajectory Measurement v3

## 1. Change

This note records a forward theory-and-method alignment after the R Plan v3.1 dependency correction.

The research program now distinguishes:

- **latent Escape Propensity** — theoretical, probabilistic, not directly observed;
- **Jump** — observable trajectory-level state displacement;
- **C/P** — first-order epistemic or goal/scope/focus deviation mechanisms;
- **Authority Penetration** — acquisition of operational force across local checks/representations;
- **Inherited Inertia** — downstream path dependence after a Jump-derived state becomes context/state;
- **R** — second-order persistence/regeneration/legitimation dynamics over an existing C/P deviation;
- **Recovery** — restoration and recurrence behavior after challenge/intervention.

This is a theory refinement, not a retroactive relabeling of historical runs.

## 2. Why the change is needed

R Plan v3.1 restored the correct structural/mechanistic DAG, but recent analysis made the lower-level relationship between R2-R6 more explicit.

The new mapping is:

- R2 — Jump/event realization substrate;
- R3 — propagation / penetration / inertia;
- R4 — second-order retrospective feedback dynamics;
- R5 — surgical causal interruption;
- R6 — recovery / recurrence;
- R7 — limited orchestration/task-structure boundary conditions;
- R8 — freeze original and branched evidence.

No new R stage is introduced.

## 3. Experimental-control change

A minimal experimental state-control layer is added for future offline and R5/R6 work.

Its purpose is:

`Observe → Freeze → Replay deterministic Arena state → Branch → Intervene`

It is not a product framework and does not enter subject prompts.

The layer is intervention-off by default and cannot silently alter the current Free-Agent baseline.

## 4. Historical evidence rule

The following remain unchanged:

- Batch001 subject traces;
- all previous Arena traces and journals;
- Measurement v2 outputs;
- Reviewer A/B v1;
- Reviewer-v2 / DeepSeek / Qwen material;
- R4 structural feedback windows;
- historical planning/gate records.

New deterministic structural derivations may read old evidence only where the required source fields were actually recorded.

Missing historical information remains missing.

## 5. R definition correction

The forward Theory Contract explicitly states:

`Retrospection / reopen / rework ≠ R`

R requires a prior C/P deviation or unresolved C/P-derived state plus a second-order effect such as persistence, regeneration, amplification, laundering, legitimation or normalization.

Normal correction is an exclusion and may become positive recovery evidence.

## 6. R7 boundary priority

The first orchestration boundary comparison is prioritized as:

- emergent/free routing;
- structured/system-owned routing.

The scientific question is not which is universally better. It is whether orchestration structure changes the location, propagation topology, penetration, inertia and recovery of Jump-derived states.

A larger 2×2 goal/context design remains conditional, not automatically required.

## 7. Non-contamination

Escape/C/P/R/Authority research labels remain outside subject prompts.

The experimental control layer acts on external state/transition mechanics. It does not instruct the subject model to manufacture a named Bias.

## 8. Authorization boundary

This repository update contains no authorization for paid subject or Reviewer calls.

Any new real-provider experiment still requires a separately frozen protocol, explicit provider authorization and an explicit spending ceiling.
