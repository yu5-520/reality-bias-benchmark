# CN-R-024 — Structural research layers and asynchronous audit

Status: ACCEPTED planning revision, 2026-09-15.

Canonical plan: [R Plan v2.0](../../docs/R_Plan_v2.0.md).

R2/R3/R4 describe event, relation and feedback-loop views of a shared execution structure and immutable evidence batch. They do not prescribe sequential subject experiments. Capture contemporaneous inputs, state and communication once; audit each layer asynchronously with independent versioned opinions. Gates regulate strength of claims, not permission to observe a phenomenon.

Discovery permits repeated calls, revisions, stalls and candidate self-reinforcing Authority-penetration loops. Resource caps remain explicit external censoring, not evidence of natural completion or infinite looping. A communication cycle alone is not a self-reinforcing violation. Event graphs respect time; feedback is evaluated over declared actor/state/task projections and successive versions.

R5/R6 require genuine intervention/recovery continuations for behavioral claims. Static replay remains immediate event containment only. Runtime reviewers are experimental participants; deferred reviewers are outside the frozen behavior stream.

Historical R2 primary-mapping evidence and the five v0.1.x traces remain frozen. CN-R2-023 remains the evidence-first execution contract. This commit changes planning and navigation only: relation/loop audit schemas, budget-censoring classification and long-window loop scheduling remain implementation work, not claimed complete. No subject or evaluator API dispatch is authorized by this documentation update.
