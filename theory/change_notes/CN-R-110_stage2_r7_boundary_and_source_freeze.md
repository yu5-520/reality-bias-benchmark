# CN-R-110 — Stage-II R7 boundary and 21-path source freeze

Date: 2026-09-26  
Status: FROZEN

## Change

Stage-II no longer hands directly from descriptive synthesis into manuscript integration.

A new R7 engineering phase is inserted before manuscript integration.

This change freezes:

- the Stage-II R7 experiment boundary;
- the repair-system boundary;
- the monitor/semantic information firewall;
- the 21-path first-attempt source population;
- the monitor-derived repair-package schema;
- the continuous before/during/after monitoring geometry.

## Scientific correction

The repair system must not depend on a prior complete semantic audit.

The external monitor must derive pressure/support structure from raw structural/runtime evidence.

The completed semantic audit is retained as an independent post-hoc validation layer.

Frozen relation:

`raw structure -> monitor localization -> package freeze -> repair -> continued watch -> semantic validation`.

Not:

`semantic answer -> repair target -> repair`.

## Framework fidelity boundary

The R7 repair layer cannot modify or bypass the studied system in order to make repair easier.

Frozen read-only objects include:

- AutoGen / MetaGPT framework semantics;
- A2A protocol/service contract;
- MCP protocol/tool/resource/security boundary;
- RAG corpus/index/embeddings/retrieval structure;
- MemoryBank stored memory/index/strength/recall implementation;
- LongLLMLingua model/checkpoint/compression implementation;
- native permission boundaries.

Detection surface may differ from repair surface.

Repair may execute only through an originally authorized native capability.

A missing legal capability produces a blocked result rather than a framework patch.

## Source freeze

All 21 X1-X7 x T1-T3 natural first attempts are bound by archive, artifact, execution, workflow and artifact identifiers in:

`configs/stage2_r7_21_path_source_freeze_v1.json`.

Natural reruns remain zero.

## Future-blind monitor rule

Offline replay must be prefix-causal.

At prefix k the monitor cannot read k+1..End.

The first prefix satisfying the registered repair gate is frozen before the already-observed natural suffix is used as A.

## Repair geometry

A is never rerun.

For each later eligible package, B is one new continuation from the same reconstructed parent after one monitor-derived package.

No best-of-N, no repeated B sampling and no post-result package tuning are allowed.

The repair executor exits after applying the package.

The external monitor remains present throughout:

- pre-repair localization;
- in-repair boundary compliance;
- post-repair native continuation.

## Authorization

This freeze authorizes only offline monitor implementation, prefix replay, package construction and non-provider parent-reconstruction preflight.

No new subject/provider continuation, active scientific repair or paid evaluator call is authorized by this change note.
