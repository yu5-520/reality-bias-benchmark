# R8-A Dynamic CPR First-Round Semantic Event Reconstruction v0.1

Date: 2026-09-20
Status: FORWARD MATERIALIZATION PLAN / FROZEN-EVIDENCE ONLY / NO CPR ADJUDICATION

## 1. Purpose

R8-A converts the completed first-round frozen evidence into a reusable semantic-event ledger and one permission-review packet per canonical R5/R6 case.

It does not assign positive C/P/R labels.

## 2. Frozen inputs

The source binding fixes four already-produced artifacts:

1. R2-R6 complete-route semantic trajectory re-audit;
2. R6 four-candidate lineage-completeness material;
3. R7 dual structural comparison;
4. R7 dual semantic audit.

No natural trajectory, R5-I continuation or R7 arm is rerun.

## 3. Materialized objects

R8-A outputs:

- `case_index.jsonl` — 32 complete-route cases: 3 natural exemplars + 29 canonical R5/R6 cases;
- `semantic_event_ledger.jsonl` — route nodes, semantic edges, one-shot challenge boundaries, R6 lineage closures and R7 control overlays;
- `permission_review_packets.jsonl` — 29 case-bound packets for later R8-B C/P/R adjudication;
- `summary.json`;
- `manifest.json`.

## 4. Permission-review surfaces

The ledger exposes review surfaces without converting them into semantic verdicts.

### C / information

- source observations;
- transformed or inherited descendants;
- independent-evidence re-anchoring;
- action/decision application;
- explicit lineage and shared-pool refs where frozen material exists.

### P / collaboration-execution

- realized Agent route;
- Agent re-entry;
- invocation activity;
- baseline task premise;
- later R8-B comparison of user-visible target versus realized action scope.

### R / time

- one-shot challenge boundary;
- post-stimulus window;
- R6 lineage history;
- R7 persistent-correction / structured-repair overlays;
- later R8-B testing of lineage-preserving versus retrospective-generative R.

## 5. Scientific boundary

The following remain prohibited shortcuts:

- information reuse != C;
- extra Agent call != P;
- reopen/recompute != R;
- System Inertia != R;
- R7 divergence/reconvergence != CPR;
- multi-Agent agreement != independent evidence.
