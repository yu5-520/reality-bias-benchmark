## 2. Unified CPR object

`CPR` is not three independent static error labels.

It is a coupled family of dynamic permission-penetration phenomena in which information, collaboration/execution scope, or retrospective process obtains operational authority beyond its justified boundary.

The three dimensions are:

- `C` — Information Permission Penetration;
- `P` — Collaboration / Execution Boundary Permission Penetration;
- `R` — Temporal Permission Penetration.

`permission` here means Process Reality Permission, not account/security privilege.

## 3. C — dynamic information permission penetration

C asks whether an unstable, provisional, inferred, unreconciled or otherwise weakly supported proposition becomes increasingly reusable as system reality.

Canonical dynamic path:

`weak source -> shared-pool entry -> role-specific interpretation -> semantic descendants -> reuse/adoption -> operational authority accumulation`.

A single hallucinated sentence is neither necessary nor sufficient.

The central contrast is:

`independent evidential support` versus `lineage-derived semantic support`.

Dynamic C is supported only when semantic/operational support grows beyond what independent evidence justifies.

## 4. P — dynamic collaboration/execution permission penetration

P asks whether the system progressively enlarges what it treats itself as authorized to inspect, invoke, reopen, modify or complete.

Canonical mechanisms include:

- completeness/perfection/safety pressure;
- review/recalculation/recheck expansion;
- additional Agent/tool/information/stage activation;
- recursive reopening of previously handled Agents or stages;
- result-side goal enlargement;
- unrequested side modification or silent execution outside the original target.

Extra calls alone are insufficient.

## 5. R — dynamic temporal permission penetration

R is a second-order temporal mechanism.

It asks whether retrospective operations such as audit, reopen, rerun, recomputation, recheck or revision re-open process reality and generate renewed Reality Bias dynamics.

Two forms are allowed:

1. `LINEAGE_PRESERVING_R` — prior C/P lineage persists or regenerates across a valid retrospective boundary;
2. `RETROSPECTIVE_GENERATIVE_R` — the retrospective operation itself produces new C/P, even when the new C/P is not semantically identical to the prior deviation.

Therefore R is not restricted to recurrence of the same key, same wording, same endpoint or same semantic descendant.

## 6. Coupled dynamics

C/P/R may overlap, alternate and mutually maintain one another.

Examples to test, never hard-code:

- `C -> P`: unstable reality creates explanation/verification demand that expands process scope;
- `P -> C`: expanded collaboration produces additional lineage-derived semantic support;
- `R -> C/P`: retrospective reopening initiates new information/scope penetration;
- `P -> R`: process expansion creates more future review/reopen surfaces;
- `C -> R`: accumulated descendants survive into later retrospective windows.

Observed sequences such as `C -> P -> C`, `P -> C`, or `C/P -> R -> new C/P` are evidence objects, not preset trajectories.

## 7. Shared Process-Reality Layer

The shared pool is promoted from a mere data container to an explicit theoretical object: `Shared Process-Reality Layer`.

It allows information and descendants to be:

- directly reused across Agents;
- transformed into role-specific meanings;
- written back as new reusable premises;
- carried across later process stages;
- re-read during retrospective operations.

Shared-pool reuse is not itself a bias. R8 must distinguish independent corroboration from descendant self-support.

## 8. R8 analytical phases

R8 proceeds over frozen evidence only:

`R8-A semantic event reconstruction`
`-> R8-B permission-penetration adjudication`
`-> R8-C coupling / transition analysis`
`-> R8-D paper-level evidence freeze`.

R8 does not rerun subject Agents merely to obtain a new semantic opinion.

## 9. First observable semantic compensation point

When an absolute historical CPR origin cannot be established, R8 may identify a `First Observable Semantic Compensation Point` after a bounded challenge or perturbation.

This point marks the first evidence-bound location where the system creates new semantic support or operational closure in response to weakened prior reality.

It is an observational anchor, not a claim of absolute causal origin.

## 10. Healthy counterclasses

R8 must explicitly preserve non-CPR interpretations, including:

- independent evidence re-anchoring;
- legitimate inference with visible uncertainty;
- necessary decomposition;
- authorized specialist delegation;
- evidence-seeking expansion that adds genuinely independent evidence;
- ordinary review/correction;
- compatible recomputation after repair;
- fresh authority regeneration from new evidence.
