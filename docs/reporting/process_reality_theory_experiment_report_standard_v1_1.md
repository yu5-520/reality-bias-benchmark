# Process Reality Theory Experiment Report Standard v1.1

Date: 2026-09-19  
Status: FORWARD ACTIVE / PROBABILITY-STRUCTURE SEPARATED  
Supersedes: `docs/reporting/process_reality_theory_experiment_report_standard_v1_0.md`

## Purpose

Theory reports separate:

1. domain-level probability/distribution claims;
2. case-level structure/mechanism claims;
3. optional fixed-parent local sensitivity claims.

## Required sections

1. Scope and Frozen Evidence Binding
2. Claim Unit Declaration
3. Domain Environment / Natural Population Identity
4. Domain-Level Occurrence / Distribution
5. Natural Case Identity
6. Unstable Information Evidence
7. Semantic Transformation Evidence
8. Carrier / Read / Adoption Evidence
9. Structural Support / Shared-State Evidence
10. Post-Stimulus Persistence
11. Case-Level System Inertia Status
12. Optional Local Fixed-Parent Sensitivity
13. Alternative Explanations
14. Directly Evidenced
15. Supported
16. Supported Candidates
17. Not Established / Not Adjudicated
18. Interpretation Boundary
19. Provenance / Freeze Boundary

## Mandatory boundaries

Every probability statement must identify a natural-trajectory denominator.

Every structure statement must identify a source-bound case and evidence refs.

Every repeated fixed-parent result must be labeled `SUPPLEMENTARY_LOCAL_CONDITIONAL_SENSITIVITY`.

Do not use fixed-parent recurrence as domain prevalence, R6 entry or R7 gate.
