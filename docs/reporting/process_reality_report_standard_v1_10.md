# Process Reality Report Standard v1.10

Date: 2026-09-26  
Status: **FORWARD ACTIVE / STAGE-II CHILD-REPORT EVIDENCE BUNDLE**  
Predecessor: `RB-PROCESS-REALITY-REPORT-STANDARD-v1.9`

Historical reports and the frozen Stage-II General Chapter v1.0 remain immutable.

This version retains every requirement of v1.9 and adds a Stage-II child-report evidence bundle that can represent a single software-engineering domain with heterogeneous system layers without forcing the earlier three-domain R-series schema onto Stage II.

## 1. Core evidence chain

Forward Stage-II child reports use:

`Frozen Evidence -> Complete Recorded Route -> Semantic Lineage Overlay -> Node/Edge Semantic Audit -> Realized Process Contrast -> Supporting Structural/Carrier Data -> Claim Boundary -> Provenance`

Semantic audit remains the primary interpretive content.

## 2. Parent General Chapter

Parent interpretation contract:

`docs/reports/2026-09-26/StageII_General_Chapter_Process_Reality_Methodology_and_Hypotheses_v1.md`

Machine-readable parent claim IDs:

`configs/stage2_general_chapter_claim_registry_v1.json`.

Every child report that uses the parent chapter must preserve the v1.9 anti-circularity rule.

## 3. Stage-II child evidence bundle

New Stage-II child reports use:

`RB-PROCESS-REALITY-REPORT-EVIDENCE-BUNDLE-v0.2`

defined in:

`schemas/process_reality_report_evidence_bundle_v0.2.schema.json`.

The bundle must bind:

- the General Chapter version and claim IDs used;
- the frozen 21-cell Stage-II population accounting;
- selected source-bound trajectory cases;
- complete recorded-route status;
- semantic node/edge ledger references;
- figure specifications;
- independent evidence references;
- explicit claim boundaries;
- provenance and zero-mutation status.

The earlier v0.1 report bundle remains valid for its historical R-series report family.

## 4. Complete-route rule

For every primary semantic case:

- all runner-recorded route nodes remain visible in the route material;
- when a native event stream is the primary route representation, the report must state this explicitly;
- target-relevant semantic nodes are an overlay, not a replacement for the route;
- missing hidden semantics must remain missing.

At least one primary report figure must be a:

`TIME_ALIGNED_ACTUAL_AGENT_ROUTE_WITH_SEMANTIC_LINEAGE_OVERLAY`

with all recorded route nodes for that case represented.

## 5. Semantic-content rule

Every major semantic node/edge reported must preserve:

- semantic before;
- semantic after;
- semantic delta;
- producing/reading actor;
- propagation or relation type;
- evidence ref;
- claim status.

Taxonomy labels alone are insufficient.

## 6. Heterogeneous-layer rule

Stage II must not normalize all X systems into one artificial execution layer.

Reports must distinguish:

- native multi-Agent framework;
- inter-Agent protocol;
- tool/resource protocol;
- retrieval capability;
- memory capability;
- context-compression capability.

A capability-layer X may share the frozen de-instrumented software-engineering host only where the X condition does not own scheduling or inter-Agent transport.

## 7. Process / endpoint rule

`same endpoint != same process`

and

`different process != automatically worse process`.

A child report may compare realized process structures but may not convert n=1/cell natural evidence into:

- framework ranking;
- prevalence;
- universal reliability ordering;
- named-framework causal effect.

## 8. Observer rule

The monitor may be described as non-interfering only when the frozen registry marks it external/non-mutating and the observed evidence surface is stated.

The report must not imply full access to unexposed internal semantics.

## 9. Hypothesis wording

General-Chapter hypotheses remain bounded by their registry status.

Use:

- DIRECTLY_EVIDENCED for directly frozen execution/observer/repository facts;
- SUPPORTED or SUPPORTED_CANDIDATE for bounded semantic/process readings;
- NOT_ESTABLISHED for causal, prevalence, efficiency, or universal claims not tested by the design.

## 10. Resource-comparison rule

No R-versus-Stage-II token/resource efficiency claim may be promoted without a frozen common denominator.

## 11. Required child-report section

Every new Stage-II child report includes:

### Relation to Stage-II General Chapter

with:

1. adopted methodological IDs;
2. hypotheses informed;
3. independent evidence contributed;
4. claim boundary.

## 12. Authorization boundary

This standard authorizes no subject/provider/evaluator call, natural rerun, C3/C4 contrast, repair action, or reconstruction of unobserved semantics.
