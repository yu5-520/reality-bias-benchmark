# Process Reality Theory Experiment Report Standard v1.2

Date: 2026-09-19
Status: FORWARD v5.4
Predecessor: v1.1

## Mandatory experiment accounting

Every report must separately state:

1. natural trajectory population size;
2. selected source-bound case count;
3. existing frozen natural references;
4. canonical new R5-I trajectories;
5. R6 new provider trajectories;
6. canonical new R7-P trajectories;
7. canonical new R7-S trajectories;
8. supplementary repeated trajectories;
9. provider calls/tokens/spend.

Historical executed branch count must not be substituted for canonical scientific case count.

## Canonical R5 statement

Use:

`N0 existing + R5-I once`.

Do not describe newly sampled same-parent controls as the natural baseline.

## Canonical R7 statement

Use:

`R7-P once + R7-S once`.

C1/R5-I is frozen reference evidence and is not a new R7 arm.

## Probability boundary

Case/intervention counts are not domain-level prevalence denominators.

## Semantic boundary

Realized structural support, System Inertia candidate status, problematic bias and CPR must remain separate claims.
