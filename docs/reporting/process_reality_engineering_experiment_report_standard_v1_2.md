# Process Reality Engineering Experiment Report Standard v1.2

Date: 2026-09-19
Status: FORWARD v5.4
Predecessor: v1.1

R7 engineering reports use the canonical dual-intervention matrix.

## Required references

- N0 natural frozen evidence;
- R5-I frozen transient intervention;
- R6 affected-lineage evidence;
- Repair Anchor / content address;
- Semantic Lineage Package;
- Lineage Completeness Gate;
- RepairClosure.

## R7-P section

Report one realized persistent-semantic trajectory:

- direct exposure count;
- reinjection count;
- downstream semantic/decision effects;
- terminal result separately.

## R7-S section

Report one realized structured-repair trajectory:

- repair packet/application hash;
- invalidated affected refs;
- reopened dependent recipients;
- recomputed descendants;
- old-lineage re-entry;
- preserved unrelated/compatible structure;
- terminal result separately.

## No canonical replicate aggregation

Do not use replicate majority, mean success rate or same-parent recurrence as the canonical engineering success criterion.

Additional repeats, if any, belong in a supplementary robustness section.

## CPR boundary

Engineering recovery does not itself adjudicate CPR.
