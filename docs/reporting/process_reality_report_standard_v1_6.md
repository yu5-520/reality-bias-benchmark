# Process Reality Report Standard v1.6

Date: 2026-09-18  
Status: FORWARD ACTIVE / SPLIT THEORY AND ENGINEERING REPORT FAMILIES  
Predecessor: `docs/reporting/process_reality_report_standard_v1_5.md`

## 1. Report-family split

Forward Process Reality work uses two experiment report families.

### Theory Experiment Report

Uses:

`docs/reporting/process_reality_theory_experiment_report_standard_v1_0.md`

Purpose:

`formation + persistence + mechanism boundaries`.

### Engineering Experiment Report

Uses:

`docs/reporting/process_reality_engineering_experiment_report_standard_v1_0.md`

Purpose:

`Repair Anchor + content addressing + semantic-lineage completeness + localized recovery`.

## 2. Future discussion

Future-development discussion is not an experiment-report family.

It may synthesize implications after theory and engineering claims are separately bounded.

## 3. Shared evidence discipline

Both report families preserve:

`Frozen Evidence -> Structural Facts -> Semantic/Engineering Audit -> Claim Boundary`

Historical artifacts remain immutable.

## 4. Local repair terminology

`Localized` means semantically scoped.

It does not mean a shallow event window.

## 5. Compatibility

v1.5 remains valid for historical/transition reports.

v1.6 is the forward paper-organization standard.
