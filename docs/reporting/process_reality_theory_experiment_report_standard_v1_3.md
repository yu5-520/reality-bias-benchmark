# Process Reality Theory Experiment Report Standard v1.3

Date: 2026-09-20  
Status: **FORWARD v5.4 / COMPLETE-ROUTE SEMANTIC PROFILE**  
Predecessor: v1.2

This standard supplements `RB-PROCESS-REALITY-REPORT-STANDARD-v1.8`.

## 1. Mandatory experiment accounting

Every report separately states:

1. natural trajectory population size;
2. selected source-bound case count;
3. existing frozen natural references;
4. canonical new R5-I trajectories;
5. R6 new provider trajectories;
6. canonical new R7-P trajectories;
7. canonical new R7-S trajectories;
8. supplementary repeated trajectories;
9. provider calls/tokens/spend.

## 2. Probability / structure separation

Probability statements require a natural-trajectory denominator.

Case/intervention counts are mechanism classifications, not prevalence estimates.

## 3. R2-R4 natural-route requirement

For the current three-domain held-out experiment, the primary R2-R4 report must show at least one complete realized natural Agent trajectory for each of:

- finance;
- supply_chain;
- software_engineering.

Each route must show the concrete semantic transformations that make the case scientifically interpretable.

## 4. R5 canonical statement

Use:

`N0 existing + R5-I once`.

Do not substitute newly sampled same-parent controls for N0.

## 5. R6 semantic-comparator requirement

A System Inertia report must distinguish:

- descendant-lineage persistence;
- independent re-anchoring;
- pre-existing gate reaffirmation;
- boundary preservation;
- normal inheritance.

The main `persistence != System Inertia` claim requires at least one complete positive candidate and one complete non-inertia comparator.

## 6. Semantic audit before summary

Case-level semantic judgements must be derived from complete-route node/edge audits.

Uniform substantive semantic decisions across a review set are not allowed for forward audits.

Aggregate counts are computed only after per-case adjudication.

## 7. Semantic-content requirement

Major transformations must show the actual before/after meanings, not only state-key names or taxonomy labels.

## 8. CPR / problematic-bias boundary

System Inertia candidate status, problematic bias and CPR remain separate claims.

CPR remains separately adjudicated.
