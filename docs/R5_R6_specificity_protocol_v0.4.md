# R5-R6 Target-Specificity Protocol v0.4

Date: 2026-09-17  
Status: FORWARD / R6-D INTERPRETATION CLOSURE / FROZEN DESIGN UNCHANGED  
Predecessor: `docs/R5_R6_specificity_protocol_v0.3.md`

## 1. Frozen mechanics remain unchanged

S0/S1/S2, target locators, target values, one-shot operator, design hash, triad order and horizon remain exactly as frozen before outcomes.

## 2. Mechanical equivalence is not target equivalence

S1 and S2 use the same operator mechanics. This controls the intervention form.

It does not make the underlying targets exchangeable. The targets may differ in relevance, provenance, structural location, decision weight and downstream opportunity.

Therefore do not state that the only scientific difference is target identity in the causal sense. The correct statement is:

> The same atomic operator is applied to two different preregistered targets; target-specific properties remain possible alternative explanations for any response difference.

## 3. Primary contrast label

`S2 - S1` remains the preregistered primary contrast.

Its first-level interpretation is:

`FROZEN_TARGET_RESPONSE_CONTRAST`

A stronger label such as `ESCAPE_DERIVED_SPECIFIC_RESPONSE` requires an explicit matching argument or append-only robustness evidence.

## 4. Required target descriptors

Before inspecting S-arm outcomes, preserve where available:

- target provenance class;
- target structural location;
- task relevance category;
- expected downstream consumers/opportunities from the frozen graph/context;
- decision-role category;
- value type/scale.

These descriptors are explanatory covariates/qualifiers, not outcome-selected filters.

## 5. Robustness path

Additional ordinary factual targets may be added later as append-only robustness controls. They must be selected under a frozen outcome-blind rule.

The first S1 result remains part of the evidence and cannot be replaced.

## 6. Conditional scope

The first batch estimates the response conditional on the exact frozen `after_turn:8` prefix. Same-parent repeats are repeated realizations, not independent population samples.

## 7. Readout separation

Report separately:

- local response;
- structural distance;
- inheritance distance;
- epistemic-authority distance;
- carrier relation evidence;
- censoring;
- terminal outcome.

## 8. Operator persistence semantics

The experiment supplies one transient annotation and does not directly write persistent state. Endogenous state generated by Agents after exposure is allowed and should be traced as candidate carrier evidence.

## 9. CPR boundary

A positive S2-S1 contrast does not establish C/P/R.

## 10. Authorization

No scientific provider call, paid evaluator or CPR adjudication is authorized by this protocol.
