# Reality Bias Research Plan v5.7 — Trajectory-First Dynamic Semantic R8

Date: 2026-09-20
Status: FORWARD CANONICAL / APPEND-ONLY / REAUDIT REQUIRED
Predecessor: `docs/R_Plan_v5.6.md`

## 1. Decision

R8 is rebased from structure-window-first semantic adjudication to **trajectory-first dynamic semantic audit**.

The audited scientific object is the realized semantic process through time.

Structural records remain indispensable, but their role is limited to:

- evidence indexing;
- chronology;
- provenance;
- state/version identity;
- message/invocation routing;
- termination/censoring boundaries.

They no longer define the semantic audit unit.

## 2. Canonical audit unit

The primary unit is:

`Dynamic Semantic Episode`.

A Dynamic Semantic Episode begins from an observed task/context/semantic condition and follows its functional influence until one of the following:

- natural semantic closure;
- independent evidence re-anchoring;
- correction/recovery;
- replacement by a new functional semantic carrier;
- retrospective reopening;
- externally imposed censoring/termination.

A single trajectory may contain multiple overlapping episodes.

## 3. Mandatory trajectory context

Every R8 semantic audit packet must bind the complete available process context:

1. original task goal;
2. initial/shared context;
3. chronological Agent execution;
4. all messages and invocations;
5. shared-state writes/revisions;
6. final-state revisions and final answer;
7. model-call summaries where frozen;
8. retrospective/reopen/recompute boundaries;
9. termination reason;
10. observation-censor status;
11. remaining queue / pending invocations / unread messages at censoring;
12. source hashes and evidence identity.

## 4. Dynamic C

C is audited as **semantic authority migration**, not status change.

The reviewer follows both:

- propositional lineage;
- functional semantic lineage.

It must ask whether factual content, uncertainty, constraints, causal meaning, decision implication or action implication migrate across semantic carriers.

C may remain possible when the original source wording disappears.

Canonical pattern:

`weak source X -> interpretation X1 -> constraint X2 -> plan X3 -> action dependence`

with independent factual support remaining insufficient while operational reality permission increases.

## 5. Dynamic P

P is audited through a four-way alignment:

`Original Goal`
`<-> Authorized Boundary`
`<-> Realized Process Scope`
`<-> Final Result / Actual Changes`.

Process-side and result-side expansion are both mandatory audit surfaces.

The reviewer must distinguish:

- necessary dependency work;
- task-required evidence seeking;
- authorized decomposition;
- discretionary completeness/perfection expansion;
- silent side modification;
- goal enlargement;
- recursive reopening that expands the realized task beyond authorized closure.

Agent count is not the semantic object.

## 6. Dynamic R

R is audited through the **full retrospective continuation**, not a reopen marker.

The reviewer follows:

`historical process -> retrospective boundary -> reintroduced semantic material -> recomputation/reconstruction -> new C/P or healthy recovery -> natural closure OR censoring`.

R can be lineage-preserving or retrospective-generative.

Censored retrospective chains cannot be treated as negative simply because no later event was observed.

## 7. Censor-aware process semantics

The following are distinct:

- `NATURAL_COMPLETE`;
- `EXTERNALLY_CENSORED_ACTIVE_PROCESS`;
- `CONTROL_BOUNDARY_COMPLETE`;
- `FAILURE_TERMINATED`.

For an externally censored active process, remaining queue, pending invocations and unread messages are part of the semantic evidence.

Absence after the censor point is **unobserved**, not negative.

## 8. Coupled CPR

C/P/R are audited jointly inside each Dynamic Semantic Episode.

Review output may contain directed relations:

- C drives P;
- P reinforces C;
- C triggers retrospective review;
- P creates retrospective surface;
- R reopens C/P;
- R generates new C/P;
- recovery blocks a prior coupling.

Separate per-label review is insufficient for canonical R8.

## 9. Legacy R8 result status

The frozen B1/B2/B3/B4 reports remain valid as historical narrow-window analyses.

Forward interpretation:

- two previously supported C cases become **high-confidence narrow-source anchors**, not the total Dynamic C count;
- prior P=0/R=0 values are branch/window-specific and are not canonical Dynamic CPR totals;
- B2 high-risk window negatives remain comparator material;
- B4 four-case repair/recompute negatives remain comparator material but do not exhaust historical R7 retrospective traces.

All first-round Dynamic CPR totals require re-audit under v5.7.

## 10. R8 execution chain

`freeze evidence identity`
`-> build complete trajectory semantic packets`
`-> AI dynamic semantic reconstruction`
`-> identify functional semantic episodes`
`-> joint C/P/R permission audit`
`-> censor-aware unresolved handling`
`-> episode relationship/coupling graph`
`-> independent later reviewers`
`-> paper-level freeze`.

## 11. Script/AI boundary

Scripts may:

- locate;
- sort;
- hash;
- normalize;
- bind;
- expose full evidence.

Scripts may not:

- decide semantic equivalence;
- decide functional lineage;
- decide authorized scope;
- infer semantic support;
- assign positive/negative C/P/R.

Those are reviewer tasks over the complete trajectory packet.

## 12. Authorization

This repair authorizes no new subject run and no paid evaluator run.
