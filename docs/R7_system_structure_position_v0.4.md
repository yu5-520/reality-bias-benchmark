# R7 System Structure Position v0.4

Date: 2026-09-17  
Status: FORWARD POSITION  
Predecessor: `docs/R7_system_structure_position_v0.3.md`

## 1. Position

R7 is the system-level question of whether **process inertia can be structurally steered**.

The question is broader than ALR.

ALR is one concrete **Authority-Localized Recovery** operator that can be used to test whether an inherited process displacement has locatable structural carriers and whether those carriers can be selectively revised/reopened while unrelated structure is preserved.

The forward program therefore separates:

- **R7 theory object:** structural steering / controllability of system inertia;
- **ALR treatment object:** localized recovery of an affected dependency closure;
- **persistent-field comparator:** continuous semantic exposure without ALR localization/reopen logic.

## 2. Natural/free structure remains primary

The natural Arena remains free-routing under its common experimental interfaces.

Agent ordering and realized topology are not prescribed by active ALR in the natural condition.

Passive structural observability reconstructs what happened; it does not define the target route.

## 3. Why one-shot and persistent exposure must be separated

A one-shot perturbation tests whether a local change can reorganize the path after the experiment-origin mark disappears.

A persistent-field condition continuously supplies the same correction signal.

These are different mechanisms:

```text
one-shot -> endogenous downstream inheritance
persistent field -> experiment-maintained persistence
```

Without this distinction, continuous experimental forcing could be mistaken for system inertia.

## 4. Why persistent field and ALR must be separated

Persistent field propagation keeps correction information available.

ALR additionally attempts to locate:

- the earliest authority/provenance violation;
- the affected dependency closure;
- the preserved unaffected structure;
- the revision lineage;
- the minimal subgraph that must be reopened/re-executed.

Therefore:

> field persistence studies continued exposure; ALR studies causally localized structural recovery.

A valid comparison should match semantic correction content and vary structural handling.

## 5. Three-condition position

The preferred first-paper R7 structure is:

```text
                 Frozen J0
```

This supports two nested contrasts:

- `C1 vs C2`: endogenous inertia versus experiment-maintained persistence;
- `C2 vs C3`: persistent semantic exposure versus authority-localized structural recovery.

## 6. Structural direction rather than target answer

R7 should not define direction as movement toward a desired final answer.

Direction is an observed process-topology property that may be represented through:

- actor transition order;
- edge distribution;
- state-lineage destination;
- information-flow destination;
- descendant-Jump location;
- re-entry topology;
- stage progression;
- path-family transition;
- reconvergence distance.

The downstream process remains generative.

## 7. ALR operator boundary

ALR is not a universal structured workflow.

Its minimal form is:

```text
locate earliest authority-violating ancestor n*
  -> derive dependency closure
  -> preserve unaffected structure
  -> repair violated authority/provenance condition
  -> create revision lineage/hash
  -> reopen/re-execute affected subgraph only
  -> observe downstream structure
```

A higher-level protocol may repeat the operator under preregistered conditions, but repeated feedback is not the definition of ALR itself.

## 8. Broader R7 architecture variables

The following remain valid later structural-steering variables:

- routing ownership;
- topology density;
- stage boundaries;
- context continuity/reset/compression;
- dynamic invocation surface;
- proposal/commit separation;
- Agent activation rules;
- shared-state visibility;
- handoff permissions;
- re-entry permissions.

They must not be silently described as ALR unless they are explicitly part of the frozen ALR treatment.

## 9. Scientific outcomes remain open

A structural intervention may:

- weaken inertia;
- redirect it;
- delay it;
- localize it;
- transfer it;
- recover part of the affected path;
- generate recurrence;
- create a secondary Jump;
- reconstruct a new path family;
- produce no measurable difference.

R7 does not require a monotonic treatment effect.

## 10. Preservation is part of the claim

Whole-system suppression can trivially reduce activity. That does not demonstrate localized control.

R7 must report preservation of:

- unaffected nodes;
- unaffected fields;
- unaffected branches;
- unrelated Agent work;
- non-risk path diversity.

The target is minimum necessary structural intervention, not standardization.


Structural evidence remains prior to semantic adjudication.
