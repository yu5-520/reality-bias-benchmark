Date: 2026-09-17  
Status: FORWARD / PROCESS-REALITY MECHANISM CONSOLIDATION

## 1. Version decision

v4.2 preserves all historical plans, contracts, runtime evidence, frozen reports, reviewer outputs, and manifests. It does not retroactively reinterpret the formal R5-MID frozen batch or authorize new paid provider calls.

This revision consolidates the forward mechanism path without declaring the earlier R6 or R7 concepts wrong. The change is one of abstraction and role clarification:

- the detailed post-Jump questions already present in R6 are summarized by the higher-order construct of **post-reorganization system inertia**;
- the structured-routing question already present in R7 is reinterpreted as the mechanism by which **ALR performs sustained, lineage-aware, field-level recovery/control of risk-bearing inertia**, rather than as a generic template-workflow comparison;
- R8 expands from evidence freezing alone to **CPR semantic closure, adjudication, and final evidence freeze**.

## 2. Research axis

The primary research axis remains **Process Reality Fidelity**, not terminal task accuracy.

```text
Natural free multi-Agent process
  -> observable local Jump
  -> inherited system inertia
  -> propagation / crossing / branching / re-entry
  -> one-shot local perturbation
  -> downstream path reorganization
  -> post-reorganization inertia transition
  -> structured risk-bounded recovery/control
  -> CPR semantic closure
  -> external robustness / replication
```

Outcome validity remains a terminal observation and auxiliary diagnostic.

## 3. Observation does not prescribe the observed topology

The natural Arena may use common experimental interfaces, role/responsibility definitions, and action protocols, but the observed topology is not prescribed by ALR path ordering, lineage prompts, recovery routing, or a required input/output workflow.

The forward evidence stack distinguishes:

1. **raw observable facts** — message, invocation, state read/write, actor, turn, state transition, final/revision and other recorded runtime facts;
2. **derived structural measurements** — Jump, lineage, descendant relation, path family, inertia, dependency closure and affected subgraph;
3. **semantic adjudication** — CPR and related semantic interpretations applied only after structural evidence is frozen.

The measurement layer may make naturally realized structure observable; it must not be treated as evidence that the observation framework created that structure.

## 5. R5 — one-shot perturbability, not inertia control

R5 keeps the established invariant:

```text
Frozen natural J0
  |- A: unchanged continuation
  `- B: one-shot local perturbation
       -> exactly one direct experiment-origin exposure
       -> consume intervention
       -> no persistent experiment-origin mutation
       -> no reinjection
       -> free continuation
```

R5 establishes **perturbability** if matched continuations become structurally distinguishable. It does not establish that system inertia has been controlled.

A single local correction cannot logically be assumed to control a process whose defining property is historical inheritance across later nodes.

## 6. R6 — conceptual consolidation into system inertia

R6 does not replace the original fine-grained post-Jump questions. It consolidates them.

The original R6 observations remain first-class measurements:

- whether later Jumps still appear after J0 is modified;
- whether later Jumps are the same family/type or transformed;
- whether Jump-derived state disappears, persists, transfers or is inherited downstream;
- whether a retrospective/challenge process brings a prior Jump-like state back;
- whether a returned Jump is the same type, a transformed type or an independent new Jump;
- whether a returned/transformed Jump is itself inherited again;
- whether delayed re-emergence, residual lineage, reconvergence or extinction occurs.

These observations are summarized at a higher level as **post-reorganization inertia dynamics**.

Useful structural summaries include:

- retention;
- decay/extinction;
- deflection;
- transfer;
- transformation;
- replacement;
- reconstruction/hybridization;
- delayed re-emergence;
- rebound/regeneration;
- reconvergence.

Recovery, residual and recurrence are therefore possible R6 manifestations, not the definition of R6.

## 7. R7 — structured routing as inertia-recovery routing

The original Free Routing vs Structured Routing question remains relevant, but v4.2 narrows its interpretation.

Structured routing is not a claim that production Agent systems should be converted into fixed workflows. In the forward mechanism program, structured routing is the temporary and local recovery structure used after a risk-bearing Jump/lineage has been frozen and localized.

The intended lifecycle is:

```text
free process
  -> risk-bearing Jump/field lineage localized
  -> freeze affected recovery scope
  -> structured recovery routing activated
  -> field-level repair/revision
  -> controlled downstream propagation
  -> observe residual / recurrence / secondary Jump
  -> re-repair if required
  -> release condition satisfied
  -> return to free routing
```

The active ALR loop is:

**Locate -> Structure -> Repair -> Propagate -> Observe -> Re-repair -> Release**

J0 is the localization entry point; the risk-bearing **field lineage and affected dependency closure** are the control objects.

R7 therefore tests **controllability**, not merely perturbability.

## 8. ALR observational and active modes

### Passive observability mode

Used throughout the natural mechanism study:

- does not prescribe Agent order or path topology;
- does not require lineage-aware prompts from subjects;
- records raw system behavior;
- reconstructs source-backed structural relations after or alongside execution;
- supports Jump localization, lineage reconstruction and inertia measurement.

### Active recovery/control mode

Activated only under a named R7 treatment:

- freezes/localizes a risk-bearing Jump and field lineage;
- derives the affected dependency closure;
- preserves unaffected structure where possible;
- uses structured recovery routing over the affected scope;
- records field revisions, provenance and downstream descendants;
- iterates recovery according to observed residual/recurrence state;
- exits when a preregistered release condition is met.

ALR is therefore not a one-shot Jump repair function. It is a lineage-aware structural feedback framework for localized inertia recovery/control.

## 9. R7 success is risk control plus freedom preservation

A system that suppresses all behavior could trivially suppress risk. That is not sufficient evidence of useful structural control.

R7 must jointly report:

### Risk-control outcomes

- risky descendant reach/depth;
- residual risk-bearing field state;
- recurrence/rebound;
- affected Agent count;
- secondary Jump formation;
- time/distance and recovery rounds to containment/release.

### Freedom-preservation outcomes

- unaffected nodes preserved;
- unaffected branches preserved;
- unnecessary reopen/rerun count;
- non-risk Agent participation retained;
- non-risk path diversity retained;
- scope of structured recovery relative to the realized process graph.

The target is **minimum necessary structural intervention**, not process standardization.

## 10. R8 — CPR semantic closure and evidence freeze

R8 operates after structural evidence is fixed.

It contains two inseparable but distinct contracts:

1. **CPR Definition Contract** — freezes what C, P and R mean, including exclusion boundaries;
2. **CPR Adjudication Contract** — freezes what evidence reviewers may use, how candidates become adjudicated findings, how disagreement is retained, and how unresolved cases remain unresolved.

Required order:

```text
raw evidence
  -> frozen structural derivation
  -> bounded semantic-review packet
  -> CPR adjudication / disagreement record
  -> theory-proposition mapping
  -> paper-level evidence freeze
```

A structural candidate is not automatically semantic C/P/R.

Existing evidence frozen as `NOT_ADJUDICATED` must remain historically `NOT_ADJUDICATED` if its freeze contract forbids later semantic adjudication. R8 must create new append-only interpretation/review objects rather than rewrite protected evidence.

## 11. R9 — external robustness

R9 remains supplementary robustness / external replication:

- independent semantic reviewers;
- additional model families;
- additional domains;
- independent implementation or laboratory replication.

R9 does not become a prerequisite that forces the first paper into a compute-scale competition.

The first paper must keep structural fact, semantic interpretation and terminal outcome visibly separated.
