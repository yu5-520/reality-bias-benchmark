# Cross-Domain Case Progression Contract v0.2

Date: 2026-09-19  
Status: FORWARD v5.3 / PROBABILITY-STRUCTURE SEPARATED  
Supersedes: `docs/cross_domain_case_progression_contract_v0.1.md`

## 1. Domain probability state space

`DOMAIN_ENVIRONMENT_FROZEN -> NATURAL_TRAJECTORY_POPULATION_FROZEN -> DOMAIN_OCCURRENCE_DISTRIBUTION_DERIVED`

This state space uses natural trajectories only.

## 2. Case structure state space

`NATURAL_CASE_FROZEN -> STRUCTURAL_CANDIDATE -> LOCALIZED_SEMANTIC_AUDIT -> [eligible] R5_PROBE_FROZEN -> R6_PASSIVE_STRUCTURE_DERIVED -> LINEAGE_COMPLETENESS_GATE -> [if complete + separately authorized] R7_REPAIR_FROZEN`

The two state spaces must not be collapsed.

## 3. R6 outputs

Valid case-level outputs include:

- `CASE_LEVEL_CARRIER_PROPAGATION_SUPPORTED`;
- `CASE_LEVEL_POST_STIMULUS_PERSISTENCE_SUPPORTED`;
- `CASE_LEVEL_SYSTEM_INERTIA_SUPPORTED`;
- `INSUFFICIENT_STRUCTURE_EVIDENCE`;
- `LINEAGE_GAP`.

## 4. Optional local sensitivity branch

`R6_PASSIVE_STRUCTURE_DERIVED -> [optional] SUPPLEMENTARY_LOCAL_CONDITIONAL_SENSITIVITY`

This branch may annotate local recurrence but returns to the same case.

It cannot alter domain-level probability.

## 5. R7 gate

R7 requires case-level lineage completeness and separate authorization.

Fixed-parent recurrence frequency is not required.

## 6. Cross-domain rule

Probability is compared across domain-level natural trajectory populations.

Mechanisms are analyzed inside each realized source-bound case.

No domain must reproduce another domain's exact path.
