## Purpose

R5 asks what happens to one already-realized source-bound case after one minimal semantic/epistemic intervention.

## Evidence pair

`N0 frozen natural continuation + R5-I single intervention continuation`

N0 already exists and must not be regenerated.

## Current operator family

The current atomic operator is a one-shot copied-runtime-view metadata transition:

`fact -> unconfirmed`

It is visible on the first resumed Agent turn only, does not mutate persistent Arena state and is never re-injected by the experiment.

## Canonical geometry

Per case:

- existing natural reference count: 1;
- new control count: 0;
- new intervention count: 1;
- canonical replicate count: 1;
- new provider branch count: 1.

## Prohibited forward defaults

Canonical R5 must not automatically create:

- same-parent synthetic controls;
- matched control/intervention pairs;
- second intervention replicates;
- order rotations.

Those remain optional supplementary local sensitivity modules only.

## Freeze

The one R5-I continuation is frozen before R6.

R6 then consumes N0 + R5-I offline.

## Authorization
