## 4. R8-B branch adjudication

### 4.2 R8-B2 — R2-R4 natural Dynamic CPR audit

- Does weak information gain operational permission naturally?
- Does collaboration/process scope exceed its supported closure?

### 4.3 R8-B3 — R6 mechanism-window audit

B3 must audit the R6 complete routes without using final System Inertia class as the semantic answer.

- descendant carrier versus independent re-anchor;

- internal review/recompute versus ordinary continuation;
- process expansion versus necessary decomposition.

### 4.4 R8-B4 — R7 retrospective/recompute audit

B4 must audit both R7 arms.

R7-S asks what the system creates after internal repair, invalidation, reopen and recomputation.

Dynamic R requires a supported post-boundary C and/or P event.
