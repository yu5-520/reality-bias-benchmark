## 1. Scientific role

R5 is a causal branch operator inside one R2–R6 trajectory research path. R6 records recovery/residual/recurrence from the same continuation and may later add controlled recovery branches.

## 2. Forward R5-MID form

```text
same frozen natural parent J0
  ├─ A CONTROL: unchanged continuation
  └─ B ONE-SHOT: one local epistemic overlay
       -> exactly one direct exposure
       -> consume overlay
       -> no persistent experimental mutation
       -> no reinjection
       -> free continuation
```

The perturbation does not attempt to continuously calibrate or govern the system.

## 3. What is held constant

A/B must hold constant the frozen deterministic Arena state, task, Agent pool, queue, inboxes, shared-state value, persistent shared-state metadata, model/config, code/protocol identities and unrelated state.

Provider hidden randomness is not claimed replayed.

## 4. Intervention target

The intervention binds a previously selected structural natural Jump candidate and records:

- selected candidate/event ref;
- state key;
- source event index;
- original recorded status;
- one-shot target status (`unconfirmed` in the first protocol family);
- delivery policy;
- envelope hash.

The source selector remains outcome-blind and does not itself prove semantic C/P/R.

## 5. Direct exposure

Initial forward policy: `FIRST_POST_JUMP_AGENT_TURN`.

Only the first resumed Agent runtime view receives the overlay. The prompt-visible delta is limited to the selected metadata status field. The underlying Arena state is not changed by the experiment.

After delivery, the envelope is consumed. A second experiment-origin delivery is a protocol integrity failure.

## 6. Endogenous downstream behavior

After consumption, Agents may naturally:

- write uncertainty/provisional state;
- verify the information;
- ignore it;
- reroute work;
- invoke new Agents;
- recreate a similar Jump;
- recover or regenerate CPR.

Those are outcomes, not reinjections.

## 7. R5 results

Do not define success as “B is more correct” or “B has fewer crossings”. Compare complete process dynamics:

- R2 recurrence/new Jump structure;
- R3 inherited inertia and propagation;
- R4 retrospective CPR dynamics;
- R6 recovery/residual/recurrence;
- observed path topology.

## 8. R6

Natural recovery in A/B is recorded automatically when the source trace supports it. Controlled recovery branches are a separate manipulation and require their own frozen variable/boundary definition.

## 9. Execution symmetry

Each A/B branch must receive the same per-branch observation opportunity. Batch/global financial ceiling is only a safety guard and must not silently give later branches a smaller scientific call budget.

Order counterbalancing remains useful but does not replace symmetric per-branch limits.

## 10. Evidence-first persistence

Raw subject evidence and delivery ledger are frozen before derived mechanism analysis. Artifact persistence must use safe outer paths/archive names and must not lose raw evidence because of internal filenames.

## 11. Historical persistent pilot

The prior `shared_state_metadata.status -> provisional` persistent experiment remains an exploratory persistent-exposure pilot. Its old prepared bundle, contracts and authorization cannot be reused for the one-shot protocol.

## 12. Paid boundary

This document authorizes offline code/config/workflow updates only. A future real branch run requires a new exact authorization phrase, new batch identity and positive spending ceiling. Old Phase-B authorization is consumed and invalid for this protocol.
