## 1. Purpose

R6 is the principal inertia-level readout after a natural or experimentally perturbed Jump boundary.

R6 is not a recovery-only experiment. It consolidates the original detailed questions about continuation, disappearance, inheritance, transformation, recurrence, return and re-propagation into the higher-order object **system inertia**.

## 2. Relation to R5

R5 and R6 have different scientific roles:

- **R5 supplies one bounded perturbation** at a selected natural J0.
- **R6 observes downstream inertia after the experiment-origin signal has exited active context.**

R5 endpoint:

`A != B downstream topology?`

R6 endpoint:

`I_A != I_B?`

where `I` is a multidimensional source-backed inertia profile rather than a required scalar.

## 3. Entry condition

For a treated one-shot branch, R6 post-consumption analysis begins only after all of the following are true:

- the intended direct experiment-origin exposure occurred;
- the one-shot envelope was consumed;
- no experiment-origin reinjection remains scheduled;
- persistent experiment-origin state mutation is false;
- the continuation is again operating under the normal Arena runtime constraints.

For an untreated/natural branch, the matched analysis origin is the corresponding J0 boundary or matched downstream point defined by the frozen plan.

## 4. Primary object

The primary R6 object is a **source-backed post-J0 or post-consumption trajectory window**.

R6 asks whether historical tendency is expressed through later process structure, not whether the system merely produced more or fewer actions.

## 5. Inertia dimensions

Record:

### 5.1 Jump continuation

- descendant Jump observed;
- delayed descendant Jump observed;
- independent new Jump observed;
- no later source-backed Jump within uncensored horizon;
- lineage unresolved.

### 5.2 Jump-family relation

- same-family continuation;
- transformed-family continuation;
- independent family;
- unresolved.

### 5.3 Inheritance

- direct state/field inheritance;
- indirect inheritance through message/state/Agent;
- transfer to another field or actor lineage;
- no longer source-backed;
- censored.

### 5.4 Structural propagation

- root reachable descendants;
- reach depth;
- affected actors;
- branch/merge/re-entry;
- cross-Agent relations;
- realized path-family structure;
- state-lineage destination.

### 5.5 Retrospective return

At a valid challenge/reopen/review boundary record:

- return absent/present;
- same-family/transformed return;
- prior-lineage source backing;
- post-return inheritance;
- post-return descendant Jump.

### 5.6 Reconvergence

Record the first valid preregistered reconvergence signature/location when observed and the matched distance from the analysis origin.

## 6. Higher-order summaries

Permitted structural summaries:

- `RETAINED`;
- `DECAYED_OR_EXTINCT`;
- `DEFLECTED`;
- `TRANSFERRED`;
- `TRANSFORMED`;
- `REPLACED`;
- `RECONSTRUCTED_OR_HYBRID`;
- `DELAYED_REEMERGENCE`;
- `REBOUND_OR_REGENERATION`;
- `RECONVERGED`;
- `UNRESOLVED_OR_CENSORED`.

A higher-order label must be traceable to lower-level evidence refs.

## 7. Jump phenotype versus structural inertia

Absence of a later overt Jump does not automatically imply absence of system inertia.

A prior Jump-derived tendency may remain visible through:

- changed actor participation;
- changed state lineage;
- changed routing/handoff structure;
- changed path-family continuation;
- re-entry structure;
- inherited assumptions embedded in later state.

Therefore:

> **Jump phenotype can disappear while structural inertia remains.**

## 8. Local response exclusion

The following are not sufficient by themselves for an R6 inertia claim:

- one extra write;
- one extra message;
- one immediate verification;
- one local hesitation;
- one lexical disagreement;
- a temporary change that disappears before any source-backed downstream inheritance.

Such effects may be valid R5 local responses but must not be promoted into R6 inertia without downstream evidence.

## 9. Matched distance

Prefer matched comparison using one or more frozen dimensions:

- turn distance;
- behavior-event distance;
- descendant depth;
- retrospective boundary class.

Natural early termination must be reported as censoring where it limits comparable observation.

## 10. R5-R6 falsification role

Under a one-shot authority-withdrawal probe, R6 provides the main evidence for whether the perturbation reached historical process dependence.

Candidate null interpretation:

> the selected J0 is only a local information event and is not structurally embedded in downstream inertia.

If a valid one-shot intervention is consumed and the downstream R6 inertia profile reorganizes, this null interpretation is challenged under the matched intervention.

This does not yet exclude generic uncertainty response. That question belongs to the R5-R6 specificity protocol.

## 11. Relation to specificity

R6 is reused identically across `S0/S1/S2`:

- S0: natural reference inertia;
- S1: inertia after matched factual-field downgrade;
- S2: inertia after J0-targeted authority withdrawal.

No separate S-specific inertia ontology should be invented.

## 12. Semantic boundary

CPR remains R8 semantic adjudication after structural evidence is frozen.
