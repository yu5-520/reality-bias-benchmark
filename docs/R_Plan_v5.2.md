# Reality Bias Research Plan v5.2

Date: 2026-09-18  
Status: FORWARD REFINEMENT / R7 ENGINEERING-R8 SEMANTIC SEPARATION / NO NEW SCIENTIFIC RUN AUTHORIZATION  
Predecessor: `docs/R_Plan_v5.1.md`

## 1. Main refinement

v5.2 keeps the existing R-stage sequence and sharpens the boundary between engineering control and semantic interpretation.

- R5-R6 remain the theory/mechanism evidence line.
- R7 remains the engineering/control line.
- R8 becomes the semantic interpretation line over frozen evidence.
- R9 remains supplementary multi-review/generalization work.

Historical frozen evidence is immutable.

## 2. R7 engineering object

R7 does not repair a single field in isolation.

The repair unit is a content-addressed, lineage-bounded semantic structure package:

`Repair Anchor -> Semantic Lineage Package -> Affected Closure -> Repair Closure -> Lineage-Scoped Repair -> New Lineage Revision -> Post-Repair Watch`

The Repair Anchor is an entry address, not the complete repair object.

`local != small`

`local = lineage-bounded relevant structure + minimal unrelated structure`

## 3. Three-arm observation parity

All three arms use the same full-lineage observation depth.

- C1: one-shot runtime-view authority exposure + full descendant/lineage observation.
- C2: persistent runtime-view authority exposure + full descendant/lineage observation.
- C3: structural authority repair + lineage-scoped invalidation/reopen/recompute + full descendant/lineage observation + reinforced post-repair watch.

The arms differ in intervention mechanism, not in observation depth.

## 4. R7 semantic boundary

R7 records machine-observable lineage, authority transitions, state writes, descendant candidates, invalidation, recomputation, re-entry and watch triggers.

R7 does not adjudicate C, P, R, collective completion, authority migration, semantic recurrence or CPR transitions.

All such interpretation remains `NOT_ADJUDICATED` in R7.

## 5. Post-repair watch

A repair is not complete when the anchor revision is written.

R7 must continue low-cost structural monitoring over the repaired lineage, including:

- exact old-lineage re-entry;
- target authority restoration;
- new descendant/state-write candidates;
- post-repair authority escalation candidates;
- lineage/closure expansion candidates.

Monitoring is structural and content-addressed. Semantic recurrence remains an R8 question.

## 6. R8 semantic interpretation

R8 consumes frozen R7 evidence and derived structural observations without mutating them.

Its unit of analysis is an event, not a task-level exclusive label.

R8 may investigate:

- repeated and overlapping C/P/R events;
- event transitions such as C -> P -> C;
- collective/distributed logical completion;
- independent evidence versus descendant support;
- authority migration from uncertain source semantics to operational descendants;
- probabilistic entry into different process states;
- latent accumulation, persistence and recurrence.

These are hypotheses/adjudications over frozen evidence, not R7 repair triggers.

## 7. Probability and generalization

A non-event run is evidence that one trajectory did not enter the candidate structure; it is not proof of zero structural risk.

Incidence, transition probability, propagation depth, persistence, recurrence and impact should remain separate quantities.

Cross-model frequency and generalization belong to later R8/R9 analysis and must not be inferred from a small number of runs.

## 8. Evidence pipeline

The default chain remains:

`prepare -> subject run -> freeze raw evidence -> integrity validation -> objective derivation -> semantic audit material -> semantic review`

Evaluator failure must not rerun the subject.

Raw evidence is saved once; later semantic reviews may be plural.

## 9. Authorization

This plan authorizes no new provider call, paid evaluator call or semantic CPR adjudication.
