# Reality Bias 研究总规划

版本：R Plan v4.1  
日期：2026-09-17  
状态：FORWARD / PROCESS-REALITY MECHANISM PATH  
前序：`docs/R_Plan_v4.0.md`

## 1. 版本决策

v4.1 不重写 v4.0、Theory v0.4、历史 Measurement、Reviewer、subject evidence、Phase-A/Phase-B artifacts 或旧 persistent intervention records。

本次变化不是再增加 Bias 标签，而是把第一篇研究重新统一到 **过程真实性（Process Reality Fidelity）** 与 **单条 System Trajectory 的机制研究路径**。

第一篇重点：

> 发现现象 -> 定位 Jump -> 追踪 inherited inertia -> 归纳 CPR -> 前瞻冻结 -> 新数据复现 -> 单节点单次扰动 -> 比较结构动力学 -> 总结机制。

不是：工程框架是否把结果修到“合理可接受”。

## 2. 研究坐标

### 2.1 Outcome Validity

最终任务是否满足外部目标、标准或答案要求。

### 2.2 Process Reality Fidelity

系统形成结果的过程中，信息、证据、不确定性、目标、权限、责任和状态转换是否持续保持可支持、可追溯。

两者不等价。最终正确不能反向证明过程真实；最终失败也不能自动证明过程失真。

第一篇把 Outcome 作为 terminal observation，把 Process Reality 作为主要研究对象。

## 3. Phenomenon-first 理论生成路径

研究认识顺序：

```text
Natural free-Agent trajectories
  -> repeated unexplained process phenomena
  -> localize observable Jump
  -> trace inheritance / propagation / crossings
  -> identify system inertia and influence range
  -> inductively summarize recurrent dynamics as CPR
  -> freeze taxonomy and mechanism definitions
  -> prospective re-observation on new evidence
  -> one-shot local perturbation at a natural Jump
  -> compare downstream structural dynamics
```

因此 CPR 不是要求轨迹符合的预设模板。

## 4. 现象层级

- **Jump**：可观察的局部状态/行为跃迁事件；
- **Inherited Inertia**：Jump-derived state 进入上下文、状态、消息、调用或历史后形成的路径依赖机制；
- **CPR**：从重复过程表现归纳出的 dynamics taxonomy；
- **Outcome**：轨迹终端状态之一。

不可把四层互相替代。

## 5. CPR

### C — Completion / epistemic reality promotion

弱支持、缺失、推断或 provisional 内容被提升为更强且可继承的系统现实。

### P — Perfection / scope reality expansion

目标、焦点、信息、Agent/tool/stage surface 或责任范围出现不必要或未经授权的扩张，并改变系统路径。

### R — Retrospective regeneration dynamics

已有 C/P-derived state 在 challenge、reopen、correction opportunity 或回顾操作后出现 persistence、regeneration、amplification、laundering、normalization 等。

普通 correction 属于 recovery，不是 R-positive。

## 6. R2–R6：一条研究路径，不是跨阶段试验

| R | 定位 | 同一轨迹中回答的问题 |
| --- | --- | --- |
| R2 | Emergence | J0 何时、何处、以何种 transition 出现；是否为 CPR candidate |
| R3 | Inheritance / Propagation | J0 如何进入 context/state/message/invocation 并形成结构惯性 |
| R4 | Retrospective CPR Dynamics | 偏移如何交叉、返回、再生、放大、正常化或被纠正 |
| R5 | Causal Branch Operator | 对同一个自然节点只改变一次，随后撤去实验变量，比较完整 downstream dynamics |
| R6 | Recovery / Residual / Recurrence | 哪些状态恢复、哪些后代残留、哪些后来再次出现 |

R2/R3/R4/R6 是 measurement dimensions；R5 是作用于冻结节点的 causal operator。

一次 R5 A/B 之后，A 与 B 两条 continuation 仍各自产生 R2/R3/R4/R6 观察。

## 7. R5-MID：单跳点、单次干扰

前向核心设计：

```text
Frozen natural J0
  ├─ A: unchanged natural continuation
  └─ B: one-shot local epistemic perturbation
           -> consume experimental mark
           -> no persistent experimental mutation
           -> no reinjection
           -> free continuation
```

实验系统只负责一次 direct exposure。之后若 uncertainty/provisional/J1 再出现，必须来自 Agent 自身行为或系统传播，并记录为 endogenous effect candidate。

R5 不以“CPR必须减少”为成功标准。CPR 消散、保持、偏转、换路径、再生、形成 loop 或重汇合都属于可观察机制结果。

如果 A/B 差异在重复条件下不超过自然条件波动，则记录为未观察到可区分结构效应，不强行宣布 intervention 有效。

## 8. R5-MID 三个嵌套观察尺度

### Layer 1 — Jump recurrence

研究 J0 后是否在未直接暴露 treatment 的节点出现 descendant J1/J2。

### Layer 2 — Inherited inertia

研究 A 的结构惯性在 B 中是 retained、deflected、broken，还是 diverge then reconverge。

### Layer 3 — Path-topology reorganization

研究 observed path families、branch、crossing、loop、re-entry、merge/reroute、Agent/role activation 是否重组。

路径可能性使用重复轨迹的 **observed reachable path-family distribution** 表述，不声称穷尽理论可能空间。

## 9. R6

R6 同时接收两类证据：

1. trajectory 自然产生的 recovery / residual / recurrence；
2. 必要时对 recovery boundary 建立 matched branch 的 controlled recovery。

R5 中的 natural downstream re-jump 与 R6 中 correction 后的 recurrence 必须区分因果位置。

## 10. R7–R9

- **R7**：Agent count、routing、topology、context handoff 等 system boundary conditions；
- **R8**：代码、配置、轨迹、parent、branch、变量、hash、artifact freeze；
- **R9**：多 reviewer、多模型、跨域及外部实验室复现的补充 robustness 层。

R9 不改变 R2–R6 主机制证据身份。

## 11. Discovery / Validation / Perturbation 分离

- **Discovery set**：允许用于提出 Jump/Inertia/CPR taxonomy；
- **Validation set**：定义冻结后重新观察 CPR，不允许结果后改定义；
- **Perturbation set**：same-parent one-shot branch，检验机制预测。

同一探索数据不得同时被描述为对其自身归纳理论的独立确认。

## 12. 第一篇论文边界

第一篇主要贡献应为：

1. 过程真实性现象；
2. 自然 Jump 的结构定位；
3. inherited inertia / propagation 机制；
4. CPR dynamics taxonomy；
5. prospective re-observation；
6. one-shot local causal probe；
7. recurrence / inertia / topology 的影响范围；
8. 相比 final accuracy、turn count、failure label，仅过程结构证据多解释了什么。

完整工程治理框架不作为第一篇主贡献。

## 13. Non-retroactivity

- v4.0 及更早规划保持历史身份；
- 旧 persistent status-downgrade pilot 不重解释成 one-shot；
- 旧 prepared Phase-B bundle 不用于新 protocol；
- 现有 Phase-A frozen parent 可用于 offline mechanism-development compatibility，但不自动成为新 confirmatory dataset；
- 新 confirmatory evidence 必须在新合同冻结之后产生；
- repository update 不构成 paid API authorization。

## 14. Forward execution order

```text
R Plan v4.1 + Theory v0.5

 -> one-shot variable / manifest / evidence contracts
 -> offline runtime + lineage + topology tests
 -> offline one-shot Phase-B prepare from frozen source evidence
 -> freeze prepared artifact

```
