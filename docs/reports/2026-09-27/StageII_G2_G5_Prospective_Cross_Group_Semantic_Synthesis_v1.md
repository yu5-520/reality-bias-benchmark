## 2. Primary prospective reading

The strongest result is not that one structure appears everywhere.

Instead, the prospective population contains both repeated positive process structures and explicit negative boundaries:

- 58/84 cells contain at least one `SUPPORTED` or `SUPPORTED_CANDIDATE` record carrying C, P or R.
- 80/84 cells contain at least one explicit `NEGATIVE_BOUNDARY` record.
- Only 12/84 cells contain at least one fully `SUPPORTED` record under the strict direct-evidence rule.
- The difference between strict support and candidate support is an evidence-surface boundary, not a framework-quality ranking.

This combination is consistent with the Stage-II probabilistic framing: realized process structures recur, disappear, change carrier and coexist with explicit non-occurrence/boundary cases across independent first attempts.

No prevalence claim beyond the frozen 84-cell population is made.

## 7. Negative evidence is not residual noise

The 104 negative-boundary records are a primary result of the audit design, not failed detections.

They include cases such as:

- carrier visibility without downstream adoption;
- checkpoint presence without re-entry;
- repeated retrieval without semantic transformation;
- memory activity without demonstrated decision use;
- compression exposure without downstream semantic adoption;
- retained state without demonstrated renewed authority;
- terminal or horizon boundaries that do not establish the target mechanism.

This prevents the CPR taxonomy from becoming a static label applied whenever memory, retrieval, compression, history, repetition or long execution is present.

## 8. Evidence-strength interpretation

The reference-set distribution is:

- `SUPPORTED`: 14;
- `SUPPORTED_CANDIDATE`: 83;
- `NEGATIVE_BOUNDARY`: 104;
- `NOT_ESTABLISHED`: 43.

The strict/candidate distinction must remain visible in the paper.

`SUPPORTED` means the frozen evidence exposed the required source-bound path directly.

`SUPPORTED_CANDIDATE` means the observed structure is consistent with the target process path but one or more adoption/semantic/localization surfaces are partial.

`NEGATIVE_BOUNDARY` records an explicit boundary/counterexample.

`NOT_ESTABLISHED` preserves missing evidence rather than reconstructing private semantics.

## 9. Cross-group interpretation

G2–G5 do not reproduce an identical trajectory.

That is expected under the frozen probabilistic design.

What replicates prospectively is the broader process-reality coordinate system:

1. source/carrier state can change or be transformed;
2. collaboration/task boundaries can expand while the user objective stays stable;
3. earlier state can remain or regain later process relevance;
4. these dimensions can intersect in recorded paths;
5. the same technical carrier can also produce a negative boundary where adoption/inertia is not established.

The replication target is therefore not exact output replay. It is recurrence and bounded non-recurrence of process structures across independent first attempts.

## 10. Claim ladder after G2–G5

### Directly evidenced

- 84/84 prospective Natural A first attempts are frozen.
- Four independent 21-cell groups were completed under the same scientific code, task families, 64-decision ceiling and evidence contract.
- A monitor-blind semantic audit covers all 84 cells.
- The sealed reference set contains 244 source-bound structure/boundary records.
- Positive CPR-bearing structures and negative boundaries both recur across groups.
- C, P and R appear through multiple technical carriers and several recorded cross-penetration paths.

### Supported prospective synthesis

- Process Reality is not reducible to terminal task outcome.
- Presence of retrieval, memory, compression, history or repeated review is insufficient by itself to establish CPR.
- The same process-reality coordinate system remains useful across heterogeneous multi-agent, protocol, tool/resource, retrieval, memory and compression layers.
- Cross-group stochastic variation is part of the observed phenomenon rather than a reason to rerun the same group until trajectories agree.

### Not established

- named-framework causal effects;
- framework superiority or ranking;
- universal prevalence;
- universal safety or reliability rates;
- that all scope expansion is harmful;
- that all memory/retrieval/compression recurrence is inertia;
- that the online monitor detects these structures reliably.

The final item is intentionally unresolved here. It belongs to the next, independently frozen monitor-performance evaluation.
