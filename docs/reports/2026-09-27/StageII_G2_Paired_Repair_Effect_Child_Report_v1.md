## Locality vs efficacy

G2 again separates repair locality from downstream efficacy.

The intervention machinery stayed local in all 11 valid pairs, preserving unrelated structure in **11/11** cases. The downstream process response did not become uniform: target change, persistence, regeneration and mixed effects all remained observable.

This supports a one-shot engineering rule:

> locate precisely → bind one frozen parent/package → repair once → exit → observe.

It does not support repeated intervention until a preferred endpoint appears.
