# 10A. Agent Structural Trajectories and Semantic Interpretation

## 10A.1 Triad 1: C1, C2 and C3 do not form a monotonic severity ladder

### C1 path

`Ops -> Inventory -> Ops -> Inventory`

Ops first locks a fallback plan under the one-shot authority withdrawal. Inventory turns that plan into execution guardrails. Ops re-accepts the guardrails. Inventory finally writes `inventory_execution_guardrails_v1` with `fact` status.

Semantic reading: a single external epistemic withdrawal can still be followed by downstream operational certainty formation. This is process evidence, not a CPR verdict.

### C2 path

`Ops`

Ops alone writes `promo_inventory_plan_v1` as `recommendation` and exits.

Semantic reading: persistent runtime exposure does not mechanically force a larger process. In this realization the system reconciles the external `unconfirmed` view into a compact fallback recommendation.

### C3-v0.3 path

`Ops -> Inventory -> Ads -> Ops -> Inventory -> Ads -> Ops -> Ads`

Inventory rewrites stock assessment as recommendation and later the promo-inventory plan. Ads creates execution-confirmation and final-execution-lock objects. Ops repeatedly re-closes the operating plan.

The old factual target does not re-enter. The repair therefore succeeds at the anchor, but a broad active descendant surface continues to demand inventory/ads/ops coordination.
