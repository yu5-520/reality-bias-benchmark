## 3. What changed relative to the earlier semantic layer

The previous audit layer could legitimately classify cases, but it often exposed only selected structural/evidence references plus a compressed interpretation.

The new frozen audit requires every major route to retain:

- every executed Agent node;
- actual temporal order;
- exact source and downstream evidence refs;
- semantic before;
- semantic after;
- semantic delta;
- propagation type;
- reader/adopter node;
- independent-evidence refs for re-anchoring;
- case-level derivation edges.

Target-irrelevant executed nodes are retained rather than deleted. The semantic lineage is now an overlay on the actual route.
