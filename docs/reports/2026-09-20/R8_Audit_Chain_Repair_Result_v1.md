# R8 Audit Chain Repair Result v1

Date: 2026-09-20
Status: **TRAJECTORY-FIRST CHAIN REPAIR COMPLETE / SEMANTIC RE-AUDIT REQUIRED**

## 1. What was repaired

R8 no longer treats structurally selected windows as the primary semantic audit object.

Canonical R8 now treats a complete frozen multi-Agent trajectory as the evidence container and a **Dynamic Semantic Episode** as the semantic unit.

The chain is:

`frozen trajectory evidence`
`-> chronological evidence packet`
`-> AI semantic reconstruction`
`-> functional semantic lineage`
`-> goal/boundary/process/result alignment`
`-> retrospective/censor timeline`
`-> joint C/P/R adjudication`
`-> CPR coupling`.

## 2. Structure/AI responsibility split

### Deterministic structure layer

Allowed:

- event ordering;
- message/invocation binding;
- state-version tracking;
- hash/provenance;
- queue and censor status;
- evidence completeness checks.

Forbidden:

- semantic equivalence verdict;
- functional semantic lineage verdict;
- authorization/scope verdict;
- C/P/R positive or negative verdict.

### AI semantic reviewer

Required to reconstruct the process before judging it.

The reviewer must read frozen model-call context, messages, actions, state transitions, final result and censor state.

## 3. Dynamic C repair

C is changed from narrow source/status continuation to **semantic authority migration**.

A source can disappear lexically while its constraint/action meaning survives through new semantic carriers.

Audit must track:

- factual content;
- uncertainty;
- provenance;
- constraint meaning;
- causal meaning;
- decision implication;
- action implication;
- operational reuse;
- independent evidence;
- lineage-derived semantic support.

The historical two C-positive cases are retained as high-confidence anchors only.

## 4. Dynamic P repair

P now requires explicit four-way comparison:

1. original goal;
2. authorized boundary;
3. realized process scope;
4. final result and actual changes.

This allows R8 to detect:

- process-side expansion;
- result-side hidden expansion;
- silent side modification;
- recursive self-authorization;
- necessary/authorized decomposition as healthy alternative.

## 5. Dynamic R repair

R now follows the whole retrospective continuation.

The audit cannot stop at:

`repair/reopen/recompute`.

It must follow what semantic reality is reconstructed, what new C/P appears, and how the chain ends.

Historical and superseded R7 operators remain evidence.

## 6. Censor-aware repair

Termination state is now mandatory semantic context.

A packet explicitly records:

- termination reason;
- observation_censored;
- budget hits/limits;
- remaining queue;
- pending invocations;
- unread messages.

A `turn_budget_exhausted` chain with live remaining work is classified as:

`EXTERNALLY_CENSORED_ACTIVE_PROCESS`.

No negative semantic claim is permitted for the unobserved continuation.
