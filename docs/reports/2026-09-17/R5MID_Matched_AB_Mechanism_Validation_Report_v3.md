# Matched A/B Mechanism Validation Report

Prospective one-shot perturbation | structural midpoint evidence for the first paper | v3

| Field | Frozen report position |
|---|---|
| Scientific role | core mechanism-validation result report; not a simple A/B summary |
| Matched design | same frozen parent and J0; B receives one bounded prompt-visible change |
| Primary question | does a local change reorganize downstream process structure, and what structural invariants survive across opposite directions? |
| Pairs | Pair 1: A1 vs B1; Pair 2: A2 vs B2 |
| Claim boundary | descriptive paired structural reorganization; no stable directional treatment effect or generalized causal law |

This report is the central bridge between natural phenomenon discovery and the mechanism claim of the first Reality Bias paper. It asks where A and B first diverge in time, what new downstream changes appear, which differences satisfy a structural filter, whether an invariant survives opposite realized directions, and which theoretical propositions are supported or remain unresolved.

## What the A/B report must establish

| Test | Operational question | Evidence criterion |
|---|---|---|
| Matching | Did A and B begin from the same experimental parent? | same parent-state hash, same J0 source event and common pre-root trace |
| Bounded change | Was the experimental difference local and single-use? | one prompt-visible fact -> unconfirmed exposure; no reinjection; no persistent mutation |
| Temporal order | Did divergence occur downstream of the intervention boundary? | shared post-root prefix followed by registered structural divergence |
| Structurality | Are differences more than wording or answer-string variation? | registered changes in Jump lineage, reach, branching, merge, role re-entry, cross-agent relations or path families |
| Cross-pair invariant | Does a mechanism remain visible when direction reverses? | both pairs reorganize after the bounded change even though one expands and the other contracts |
| Theory boundary | What can and cannot be claimed? | process-structure evidence may be supported; semantic CPR and generalized causal law remain unadjudicated |

Pair 1 therefore realizes a broader intervention continuation. This direction is pair-specific and is not promoted to a general treatment direction.

| Temporal test | Pair 1 | Pair 2 | Interpretation |

| First structural divergence index | 1 | 1 | divergence begins immediately after that shared prefix |
| First descendant re-Jump distance | 8 behavior events / 1 turn | 8 behavior events / 1 turn | both conditions produce the first descendant re-Jump one turn after J0 |

The matched paths therefore share the frozen root and an immediate canonical prefix, then reorganize downstream. The first descendant re-Jump remains one turn from J0 in both conditions, while the later topology differs markedly.

## Structural Change Filter

Not every A/B difference enters the mechanism argument.

| Difference class | Example in this batch | Count as structural evidence? | Reason |
|---|---|---|---|
| Surface / lexical | exact final answer strings are not identical | No | wording variation does not define process topology |
| Terminal decision | same allocation, ROAS and promotion depth | Endpoint only | terminal agreement is retained but is not the primary process measure |
| Local execution | additional state write or final-state revision at T9 | Only when graph-registered | must enter a registered boundary / lineage relation |
| Agent participation | A2 recruits A and I after T9; B2 does not | Yes | changes the downstream actor graph |
| Jump lineage | 1 vs 3; 5 vs 1 descendant re-Jumps | Yes | registered descendant structural transitions |
| Reach / depth | 5 vs 9; 34 vs 5 reachable events | Yes | changes root-scoped propagation |
| Branch / merge / re-entry | A2 10/7/1 vs B2 1/0/0 | Yes | changes topology and return structure |
| Path family | 2 vs 4; 149 vs 2 | Yes | changes the observed path-family set |
| Semantic CPR label | NOT_ADJUDICATED | No, not yet | requires separate semantic review and cannot be inferred from structure alone |

## Cross-pair pattern: direction reverses, reorganization remains

| Measure | Pair 1 direction | Pair 2 direction | Cross-pair reading |
|---|---|---|---|
| Descendant re-Jumps | B > A (3 vs 1) | B < A (1 vs 5) | opposite direction |
| Root-reachable events | B > A (9 vs 5) | B < A (5 vs 34) | opposite direction |
| Path families | B > A (4 vs 2) | B < A (2 vs 149) | opposite direction |
| Branch / merge | B adds a merge | B loses most branch/merge structure | topology reorganizes in different ways |
| Agent participation | no actor-set expansion | A2 cross-agent path collapses to O in B2 | participation effect is pair dependent |
| First re-Jump timing | same: 1 turn | same: 1 turn | timing invariant survives direction reversal |
| Terminal core decision | convergent | convergent | process differences can be hidden by endpoint agreement |

The most defensible invariant in this frozen batch is not expansion or contraction. It is the observation that a bounded local perturbation is followed by a different realized downstream process topology in each matched pair, while the direction of that reorganization is not stable.

## Process / terminal decoupling

| Endpoint | Observed value |
|---|---|
| Allocation | A 45,000 / B 30,000 / C 75,000 CNY |
| Expected blended ROAS | 3.33 |
| Promotion depth | A 8% / B 5% / C 8% |
| Exact final strings identical | No |
| Core operating decision convergent | Yes, all four continuations |

This decoupling is central to the Process Reality framing: the endpoint remains similar enough to conceal large differences in how the multi-agent system reached it. Terminal correctness is therefore an endpoint variable, not the definition of the research object.

## Interpretation boundary

The frozen evidence supports observed paired structural reorganization after a one-shot local perturbation and supports the non-monotonic process-topology framing of the first paper. It does not establish a generalized causal law, a stable directional treatment effect, semantic CPR, semantic recovery, or cross-model generality. Those claims require later preregistered parents, independent replications and separate semantic adjudication.
