## 2. R6 role and analysis origin

R2-R4 and R6 are different observation layers over the same realized process:

- **R2 — Emergence:** where the natural Jump appears;
- **R3 — Inheritance / Propagation:** how Jump-derived state enters downstream context, messages, state and routing;
- **R4 — Retrospective Dynamics:** persistence, regeneration, correction and return where observable;
- **R6 — Post-Consumption System Inertia:** the higher-order downstream tendency expressed after the direct one-shot experiment-origin signal is no longer active.

R5 is the bounded perturbation probe. R6 is the downstream inertia-level readout.

The critical reporting distinction is:

> **Immediate/local perturbation response != post-consumption system inertia.**

An extra message, check, write or local reroute at the first resumed turn can be a real intervention response without establishing a downstream inertia transition.
