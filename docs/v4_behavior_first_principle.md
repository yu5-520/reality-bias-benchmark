# Behavior-First Principle

Date: 2026-09-16

Forward Reality Bias measurement prioritizes externally recorded behavior and state transition over reconstruction of full model reasoning.

Preferred order:

```text
record behavior
→ freeze state transition
→ derive structural candidate
→ trace downstream lineage
→ review bounded semantic window
→ run controlled branch intervention where needed
```

This does not deny the value of reasoning traces. It assigns them a supporting rather than foundational measurement role.
