## 1. Pass A — domain probability

`frozen domain environment -> natural stochastic trajectories -> raw freeze -> structural/semantic qualification -> domain occurrence/distribution`

## 2. Pass B — case structure

`qualified natural case -> optional R5 minimal probe -> frozen continuation -> passive R6 structural derivation -> optional R7 repair`

Pass B does not re-estimate Pass A probability.

## 3. R6 passive default

R6 should normally run offline over frozen evidence.

A new provider experiment is required only when a separately named supplementary hypothesis demands it.

## 4. Optional local sensitivity

Repeated frozen-parent branches are classified as supplementary local sensitivity.

They are never implicit mandatory stages.

## 5. Reporting

Each claim must identify its unit:

- domain-level natural trajectory population;
- realized case;
- optional fixed-parent local sensitivity sample.

## 6. Authorization

This protocol authorizes no provider/evaluator execution or active repair.
