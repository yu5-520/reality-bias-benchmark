# Reality Bias First Paper R Plan v5.8 — R9 Innovation Synthesis / Prior-Art Boundary / Outlook

Date: 2026-09-20
Status: FORWARD / APPEND-ONLY / NO NEW SUBJECT EXECUTION
Predecessor: `docs/R_Plan_v5.7.md`

## 1. R9 role redefinition

R9 is no longer a mandatory compute-heavy cross-model replication stage for first-paper completion.

Forward R9 role:

`R2-R8 frozen evidence -> innovation synthesis -> prior-art boundary audit -> contribution ledger -> research outlook -> external-validation programme`.

Cross-model, cross-provider, cross-topology and independent-lab replication remain important, but are moved to **future external validation** rather than being treated as unfinished core mechanism experiments.

This is a scope decision, not an empirical claim that robustness has already been established.

## 2. R9 must answer four questions

1. **What new process structures were observed?**
2. **What new mechanisms were supported?**
3. **What methodological/engineering objects were operationalized?**
4. **What is the exact boundary between those contributions and the strongest adjacent literature?**

## 3. Innovation layers

R9 synthesizes:

- Shared Process-Reality Layer;

### 3.4 Engineering contribution

R9 synthesizes:

## 4. Prior-art boundary requirement

Every paper-level innovation claim must bind:

`nearest prior work -> what that work already establishes -> overlap -> exact difference -> frozen evidence -> allowed wording -> forbidden wording`.

No contribution may rely on absence-of-search.

The literature map must distinguish:

- peer-reviewed anchor papers;
- recent preprints / frontier-neighbor work;
- surveys / synthesis sources.

## 5. Conservative novelty wording

Preferred:

- `We distinguish...`
- `We operationalize...`
- `We provide mechanism-level evidence for...`
- `We empirically characterize...`
- `Our study differs from prior work in that...`

Forbidden without a separately verified exhaustive novelty search:

- `first-ever`;
- `the first to study multi-agent failure`;
- `the first provenance system`;
- `the first rollback/repair method`;
- `the first shared-memory governance model`;
- `the first to distinguish stored from supported`.

## 6. R9 external-validation programme

Future robustness work may test:

- model family/provider;
- communication topology;
- broadcast / peer-to-peer / blackboard / router;
- typed-message / authority protocol;
- memory architecture and scope;
- MCP/tool-agent environments;
- larger Agent pools;
- task complexity;
- independent reviewer agreement;
- independent laboratory replication.

These are future validity questions, not prerequisites for the current mechanism evidence.

## 8. First-paper scientific role

The first paper remains:

`mechanism-first, high-resolution study`.

Primary question:

> Not how often does this happen across all systems, but what exactly is happening when it does?

Prevalence, cross-model frequency and cross-topology rate estimation remain external-validation tasks.

## 9. Authorization

R9 synthesis authorizes:

- literature review;
- offline synthesis;
- report writing;
- citation mapping.

R9 synthesis does **not** authorize:

- new subject/provider runs;
- paid evaluator calls;
- mutation of frozen R2-R8 evidence.
