## 1. System-level novelty rule

The first paper should not compete for isolated primitive ownership.

Its strongest defensible innovation target is:

`Dynamic Process Reality`
+ `Functional Semantic Lineage`
+ `Trajectory-First Audit`
+ `Content Address / Hash-Evidence Lineage`
+ `Affected Closure`
+ `Lineage-Addressed Repair`
+ `Selective Recomputation`
+ `Preservation`
+ `Re-entry Watch`.

The novelty claim is therefore **architectural, mechanistic and integrative**, not a blanket assertion that every component is unprecedented.

## 2. Scale-shift boundary

Multi-Agent is:

`SUPPORTED EXPERIMENTAL REALIZATION`.

`OUTLOOK-LEVEL GENERALIZATION HYPOTHESIS`.

Do not collapse these statuses.

## 3. Reflexive-case boundary

Supplementary Note S1 is allowed to support:
