## 4. Suggested Introduction contribution block

1. **A process-reality mechanism framework.** We operationalize dynamic C/P/R permission changes and their directional coupling over complete multi-Agent trajectories.
2. **Functional semantic lineage and trajectory-first auditing.** We track how meaning, uncertainty and operational implications survive semantic carrier changes, with explicit censor-aware process reconstruction.
3. **Mechanism evidence across discovery, held-out and intervention settings.** We separate semantic continuation, permission penetration, healthy re-anchoring and scope/temporal dynamics without using a homogeneous prevalence denominator.
4. **A lineage-addressed process-integrity control pattern.** We localize affected semantic closure and demonstrate persistent correction versus selective structural repair while preserving compatible state.

## 5. Suggested abstract-level one-sentence novelty

> Rather than treating multi-Agent reliability only as terminal failure, message corruption or state recovery, we study how operational permission is dynamically constructed through semantic lineage, collaboration scope and retrospective process reuse, and show how these mechanisms can be observed and locally intervened on.
