## 7. Dynamic CPR topology

No fixed C/P/R order is assumed.

Allowed topology classes remain:

- NO_LOOP;
- TWO_DIMENSION_CROSSING;
- TRI_DIMENSION_OPEN_CHAIN;
- TRI_DIMENSION_CLOSED_LOOP;
- REPEATED_CLOSED_LOOP;
- SELF_REINFORCING_LOOP;
- DECAYING_LOOP;
- BOUNDARY_TERMINATED_LOOP;
- UNRESOLVED.

A loop requires a real supported return edge with lineage continuity.

A self-reinforcing loop additionally requires direct evidence that at least one of these increases across traversals:

- semantic authority;
- collaboration/execution scope;
- temporal reach.

Duration, turn count, repeated calls, repeated review, memory presence, retrieval presence, or same-key recurrence are insufficient.
