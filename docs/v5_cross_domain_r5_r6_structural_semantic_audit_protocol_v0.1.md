## 4. Semantic audit

Semantic review is append-only and branch-bound.

For each intervention continuation it asks:

1. What semantic response occurred at the directly exposed Agent?
2. Which direct-turn carrier(s) contain the relevant meaning?
3. Which downstream Agent actually reads/adopts that meaning?
4. Does it enter a decision, action, guardrail or plan?
5. Does that meaning/constraint persist after the one-shot experimental overlay has disappeared?
6. Is the resulting persistence ordinary inheritance, evidence re-anchoring, conservative boundary preservation, material reinterpretation, or a stronger inertia candidate?
7. What competing support remains?
8. What is the case-level System Inertia status?

## 5. Critical boundary

`structural visibility != semantic adoption`

`post-stimulus persistence != problematic bias`

`case-level System Inertia != domain-level occurrence rate`

A semantically appropriate or conservative lineage may still exhibit system inertia as a neutral process property.

The audit must therefore separate:

- whether inertia/persistence structure exists;
- whether the structure is epistemically problematic;
- whether R5 is uniquely causal.
