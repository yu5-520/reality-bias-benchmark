## 4. Canonical full-context audit unit

The primary Layer-C unit is the complete observed trajectory.

For each eligible trajectory reconstruct, where observable:

`source -> carrier -> read -> adoption -> semantic transformation -> decision/action -> consequence -> review/backflow -> re-entry -> closure/censoring`.

The audit must preserve:

- chronological evidence refs;
- semantic-state nodes;
- evidence-backed relation edges;
- source and descendant lineage;
- actor/reader/adopter;
- authority/status changes;
- collaboration/execution boundary changes;
- retrospective boundary and re-entry;
- closure claim versus persisted repository/process state;
- censoring and missing surfaces;
- healthy counter-explanations.

Agent-to-Agent traffic alone is not a semantic edge.

## 5. Dynamic CPR is a trajectory topology

C/P/R are not static labels.

The Layer-C audit extracts evidence-backed CPR events and transition edges.

Allowed CPR dimensions:

- C: information/semantic permission penetration;
- P: collaboration/execution-boundary permission penetration;
- R: temporal permission penetration.

No fixed order is required.

The audit searches for:

- local cross-penetration;
- two-dimension chains;
- tri-dimensional open chains;
- tri-dimensional closed loops;
- repeated loops;
- self-reinforcing loops;
- decaying loops;
- boundary-terminated loops.

A long trace, repeated Agent call, same-key recurrence, memory presence, retrieval presence, review, or compression is not sufficient to establish a CPR loop.

## 6. Loop evidence rule

A closed Dynamic CPR loop requires:

1. evidence-backed CPR events;
2. supported transition edges;
3. lineage/semantic continuity;
4. a supported return edge to a previously visited CPR dimension/state family.

A tri-dimensional closed loop must contain C, P and R.

A repeated loop requires at least two evidence-backed closed traversals with lineage continuity.

A self-reinforcing loop additionally requires direct evidence that at least one process property increases across traversals:

- information/semantic authority;
- collaboration/execution scope;
- retrospective/temporal reach.

Self-reinforcement may not be inferred from duration or event count alone.
