# Reality Bias Research Plan v5.0

Date: 2026-09-18  
Status: FORWARD / MAJOR METHODOLOGICAL MIGRATION / NO NEW R STAGE / NO SCIENTIFIC RUN AUTHORIZATION  
Predecessor: \`docs/R_Plan_v4.5.1.md\`

## 1. Version decision

v5.0 is a major methodological migration rather than an additive R-stage update.

It keeps historical evidence, stage names and frozen identifiers immutable while changing the forward theory object, experiment-chain organization and observability interfaces.

## 2. Forward theory chain

\`\`\`text
Multi-source information / pressure / goal / boundary
  -> Unstable Information
  -> Agent-mediated transmission
  -> Escape Structure
  -> Semantic Transformation
  -> Structural Support
  -> Stable Shared Information Pool
  -> Direct Agent Consumption
  -> Constraint / Decision / Action Persistence
\`\`\`

Observation/control chain:

\`\`\`text
Structural Exposure
  -> Structural Scout
  -> Localized Semantic Audit
  -> Upstream Trace
  -> Downstream Closure
  -> Intervention-Surface Selection
  -> Local Repair
  -> Recovery Verification
\`\`\`

## 3. Stable stage identity, changed stage responsibilities

No new R stage is added.

### R2-R4 — natural formation views

Synchronously record one natural process and later audit:

- unstable information;
- semantic transformations;
- cross-Agent adoption/coupling;
- shared-state materialization;
- structural-support candidates;
- stable-pool entry candidates;
- exposure candidates.

R2-R4 remain different analytic views of the same natural process, not mandatory sequential subject experiments.

### R5 — scout + driver probe

R5 forward role:

- structural scouting/localization;
- minimal driver discrimination.

Historical one-shot \`fact -> unconfirmed\` remains a valid minimal driver probe.

R5 does not by itself prove a unique causal root, CPR, repair efficacy or universal structural control.

### R6 — support / trace / control-surface identification

R6 maps:

\`source -> transformation -> support -> pool -> exposure -> upstream/downstream trace -> candidate intervention surface\`

Historical R6-A/B/C/D outputs remain valid frozen modules but are not mandatory future run geometry.

### R7 — localized recovery

R7 consumes an evidence-supported affected structure and an explicitly selected intervention surface.

### R8/R9

R8 remains semantic CPR closure.  
R9 remains supplementary reviewer/model/domain replication and must not become a compute-arms-race prerequisite for R2-R7.

## 4. Experimental-chain simplification

Forward core experiments prefer **Whole-Process Runs**.

One subject run should produce reusable frozen evidence for multiple later analyses rather than one run being designed around one narrow comparison whenever avoidable.

Core collection order:

\`natural run -> raw freeze -> structural index -> support/pool/exposure scout -> localized semantic audit -> optional driver probe -> trace -> optional repair -> recovery observation\`

## 5. Optional robustness modules

The following are retained but no longer mandatory in every future batch:

- historical Jump specificity;
- S1/S2/S3/S4 target-specific comparisons;
- matched ordinary-fact controls;
- re-Jump counts/distances;
- R6-D Escape/J0 specificity;
- separate R6-A/B/C/D subject batches;
- additional reviewer/model replications.

They may be activated when a specific hypothesis requires them.

## 6. Whole-process dataset principle

The expensive object is the real multi-Agent process trace.

Therefore:

- subject evidence is collected and frozen once;
- structural derivations are reproducible and append-only;
- semantic audits may be added later;
- multiple theory questions may consume the same frozen process evidence;
- new semantic reviewers do not rerun the subject;
- future variables should attach to the shared whole-process protocol rather than require a new isolated experiment chain by default.

## 7. Detection, tracing and repair separation

Forward designs must allow:

\`Detection Surface != Trace Root != Intervention Surface\`

A valid architecture may detect at an exposure anchor, trace upstream through field/provenance lineage, and repair at the source or another earlier support surface.

## 8. Cost objective

A future control-surface study may explicitly decompose:

\`Total Cost = Detection Cost + Semantic Audit Cost + Propagation Cost + Repair Cost + Audit Risk\`

Earlier source detection is not assumed optimal because early structural signal may be weak and require expensive semantic monitoring.

## 9. Historical evidence policy

No historical v4.5.1 artifact is rewritten.

Forward documents may reinterpret old evidence only through append-only, evidence-bound re-derivation that preserves original IDs, hashes and historical claims.

This plan authorizes no provider call, paid evaluator, CPR adjudication, active recovery or scientific rerun.
