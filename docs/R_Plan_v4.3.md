# Reality Bias Research Plan v4.3

Date: 2026-09-17  
Status: FORWARD / PROCESS-REALITY STRUCTURAL CONTROL REFINEMENT

## 1. Version decision

v4.3 preserves all historical plans, contracts, runtime evidence, frozen reports, reviewer outputs and manifests. It does not reinterpret or rewrite the formal R5-MID frozen batch and does not authorize new paid provider calls.

This revision makes one important conceptual correction to the forward R7 program:

- **R7 is the system-level research question of structural inertia steering / controllability**;
- **ALR is not identical to all structural steering**;
- ALR is a specific **Authority-Localized Recovery operator** that can be used as one R7 treatment to test whether source-backed inertia has locatable structural carriers and can be locally recovered without rerunning or suppressing the entire process;
- a persistent-field condition is retained as a critical comparator because continuous semantic exposure and structure-localized recovery are different mechanisms.

R6 and R8 remain conceptually unchanged from v4.2.

## 2. Research axis

The primary research axis is **Process Reality Fidelity**, not terminal task accuracy.

```text
Natural free multi-Agent process
  -> observable local Jump
  -> inherited system inertia
  -> propagation / crossing / branching / re-entry
  -> one-shot local perturbation
  -> downstream path reorganization
  -> post-reorganization inertia transition
  -> structural inertia steering / localized recovery
  -> CPR semantic closure
  -> external robustness / replication
```

Outcome validity remains a terminal observation and auxiliary diagnostic.

## 3. Evidence layers

The forward evidence stack remains separated into:

1. **raw observable facts** — messages, invocations, state reads/writes, actor/turn, revisions, queue/execution and other recorded runtime facts;
2. **derived structural measurements** — Jump, lineage, descendant relation, path family, inertia, dependency closure and affected/preserved subgraph;
3. **semantic adjudication** — CPR and related semantic interpretations appended only after structural evidence is frozen;
4. **terminal outcome** — reported separately from process evidence.

The structural representation may make naturally realized relations observable. It must not be treated as evidence that the observation framework created those relations.

## 4. R2–R9 forward map

| R | Forward role | Core question |
| --- | --- | --- |
| R2 | Emergence | Where and how does a natural Jump appear? |
| R3 | Inheritance / propagation | How does Jump-derived state enter downstream context, messages, state, invocations and paths? |
| R4 | Retrospective dynamics | How do prior deviations persist, regenerate, amplify, normalize, cross, return or get corrected? |

R numbers describe research roles and views; they do not require nine sequential subject experiments.

## 5. R5 — one-shot perturbability

R5 keeps the established invariant:

```text
Frozen natural J0
  |- A: unchanged continuation
  `- B: one-shot local perturbation
       -> exactly one direct experiment-origin exposure
       -> consume intervention
       -> no persistent experiment-origin mutation
       -> no reinjection
       -> free continuation
```

R5 establishes perturbability/path reorganization when matched continuations become structurally distinguishable. It does not establish persistent control.

## 6. R6 — inertia transition and downstream consequences

R6 remains the higher-order study of what happens after path reorganization.

It retains the original detailed observations:

- descendant Jump continuation or disappearance;
- same-family versus transformed Jump;
- direct or indirect inheritance;
- transfer across fields or Agents;
- delayed re-emergence;
- retrospective/challenge-mediated return;
- post-return inheritance;
- branch/merge/re-entry/cross-Agent continuation;
- replacement, reconstruction, hybridization, reconvergence or censoring.

Recovery, residual and recurrence remain possible R6 manifestations, not the definition of R6.

## 7. R7 — structural inertia steering, not an ALR synonym

R7 asks a broader system-level question:

> Can structural handling steer the direction or persistence of inherited process inertia, and can selected risk-bearing lineages be made observable, traceable, locally controllable and selectively reversible?

This question does not presuppose that control will succeed. Forward reporting should prefer **observed steering, localization, recovery or failure to recover** over an unqualified claim of control.

ALR is one named recovery operator inside this broader R7 question. Other structural variables such as routing ownership, handoff permissions, shared-state visibility, proposal/commit separation, context boundaries, activation surfaces or re-entry permissions remain possible later R7 boundary-condition variables, but they are not automatically ALR.

## 8. R7 three-condition mechanism comparison

The clean forward design uses the same frozen J0 / parent state and, where possible, the same semantic correction payload and observation horizon.

### C1 — One-Shot Free Continuation

```text
J0 -> one-shot exposure -> experimental mark consumed -> free evolution
```

Purpose: observe **endogenous inherited inertia** after the experiment-origin signal exits active context.

### C2 — Persistent Field Propagation

```text
J0 -> same field/signal remains available -> later node -> same field/signal remains available -> ...
```

Purpose: observe **experiment-maintained persistence**. Persistence in C2 must not be described as endogenous inertia because the experiment continues to supply the signal.

### C3 — ALR Authority-Localized Recovery

```text
J0 / authority breach
  -> locate earliest authority-violating ancestor
  -> derive affected dependency closure
  -> preserve unaffected successful structure
  -> repair the breached authority/provenance condition
  -> create a new revision lineage/hash
  -> reopen/re-execute only the affected subgraph
  -> observe downstream residual, recurrence, re-entry and reconstruction
```

Purpose: test **causally localized structural recovery** rather than continuous content exposure.

## 9. Two nested R7 contrasts

### R7-A — One-Shot vs Persistent Field

Core question:

> How does endogenous inherited inertia differ from persistence maintained by continuous experimental exposure?

This contrast prevents continuous exposure from being mistaken for system-generated inertia.

### R7-B — Persistent Field vs ALR Recovery

Core question:

> Given materially equivalent semantic correction information, does structure-localized recovery differ from merely keeping the correction signal continuously visible?

The semantic payload should be matched as closely as possible. The intended variable is the **propagation/recovery structure**, not richer correction content in ALR.

## 10. ALR operator boundary

ALR itself is defined narrowly as **Authority-Localized Recovery**.

Its recovery anchor is the earliest source-backed ancestor at which a frozen authority/provenance condition was violated, not simply the first text that looks wrong.

ALR then:

1. computes the dependency closure from that ancestor;
2. partitions the realized graph into `Affected` and `Preserved` structure;
3. changes the violated authority/provenance condition rather than prescribing a terminal answer;
4. generates a new revision identity/hash;
5. reopens/re-executes only the affected subgraph;
6. records whether old inertia survives, re-enters, transfers, recurs or reconstructs.

ALR may be applied again under a preregistered protocol if a new source-backed recovery condition is met, but iteration is not part of the definition of the operator itself.

## 11. R7 primary evidence

R7 should reuse the Process Reality structural measurement language rather than introduce an unrelated ontology.

Primary evidence includes:

- Jump / descendant Jump lineage;
- affected descendant localization;
- unaffected-node/field/branch preservation;
- root reach and depth;
- branch / merge / re-entry;
- cross-Agent relation;
- path-family shift or reconstruction;
- state inheritance;
- residual old inertia;
- recurrence;
- secondary Jump formation;
- structural steering direction;
- reconvergence distance;
- terminal/process decoupling.

Terminal task success/failure is secondary.

## 12. Fair-comparison constraints

A valid R7 comparison should hold fixed, as far as the runtime permits:

- frozen parent / J0 identity;
- task goal;
- Agent role/responsibility definitions;
- model/provider binding;
- semantic correction payload;
- passive evidence capture;
- observation horizon or explicit censoring rule.

ALR must not receive richer semantic information than the persistent-field condition merely because it uses a richer structural mechanism.

The treatment must not tell the Agent what final answer to produce.

## 13. R8 — CPR semantic closure and evidence freeze

R8 remains downstream of structural evidence.

Required order:

```text
raw evidence
  -> frozen structural derivation
  -> bounded semantic-review packet
  -> CPR adjudication / disagreement record
  -> theory-proposition mapping
  -> paper-level evidence freeze
```

A structural candidate is not automatically semantic C/P/R. Existing evidence frozen as `NOT_ADJUDICATED` remains historically `NOT_ADJUDICATED` where its freeze contract forbids later adjudication.

## 14. R9 — external robustness

R9 remains supplementary:

- additional independent semantic reviewers;
- additional model families;
- additional domains;
- independent implementation or laboratory replication.

R9 is not a prerequisite that forces the first paper into a compute-scale competition.

## 15. First-paper mechanism chain

The forward mechanism chain is now:

**Jump -> Inherited Inertia -> One-shot Path Reorganization -> Inertia Transition -> Structural Inertia Steering / Authority-Localized Recovery -> CPR Semantic Closure**

A useful shorthand is:

**observe -> explain -> perturb -> compare -> steer/recover -> adjudicate**
