# First-Paper Scope under System Behavior v4

Date: 2026-09-16  
Status: FORWARD SCOPE CANDIDATE

## Core claim family

The first paper remains a structural existence / mechanism study of Reality Bias in an AI-driven multi-agent system.

Primary claim path:

```text
observable Jump
→ downstream propagation
→ operational penetration / inherited inertia
→ targeted intervention
→ recovery / recurrence
```

## Included

- system trajectory as the analysis unit;
- node/boundary as measurement location;
- behavior/state transition as primary observable;
- C/P first-order and R second-order semantic interpretation;
- frozen-state branch experiments;
- one or more narrow MID containment manipulations;
- recovery contrasts;
- limited system-structure boundary evidence if protocol quality permits.

## Excluded from first-paper completion criteria

- direct Tension measurement;
- full PRE variable-response curves;
- complete model × domain × topology matrix;
- hidden chain-of-thought reconstruction;
- broad industrial tool/MCP/A2A ecosystem coverage;
- universal architecture ranking;
- complete cross-domain generalization.

## Tension position

Tension supplies an upstream explanation for why Escape Propensity need not be an ungrounded latent property.

The first paper may state the conceptual chain:

`controllable antecedents → Tension → Escape Propensity → Jump`

but should only make empirical claims about variables and observables actually manipulated/measured.

## CPR position

CPR remain important semantic mechanisms but are not the complete theory.

The paper should avoid framing the contribution as a three-label taxonomy. Instead, CPR are embedded in system state-deviation dynamics.

## Reviewer-efficiency position

The paper may describe the evidence-first method in which the system records complete immutable evidence, mechanically localizes behavior/state-transition candidates, and defers bounded semantic review to later human/model reviewers.

This is a methodology contribution only to the extent supported by implemented evidence and frozen protocols.
