# Stage-II v7.45: four-group natural block, independent semantic audit, monitor benchmark, then engineering batches

Date: 2026-09-26.  
Status: **G1 FROZEN; G2-G5 NATURAL BLOCK FIRST; FULL SEMANTIC AUDIT AND MONITOR EVALUATION SEPARATED; ENGINEERING B DEFERRED UNTIL NATURAL/AUDIT BLOCK CLOSES**.

## 1. Sequencing change from v7.44

v7.44 correctly froze the five-group architecture and full 21-cell natural membership, but it still allowed each prospective group to progress from 21 natural A directly into engineering eligibility/B.

v7.45 changes only the forward sequence.

The new canonical order is:

`G2 21A -> G3 21A -> G4 21A -> G5 21A`
-> `freeze all 84 prospective natural trajectories`
-> `independent full semantic audit`
-> `experimental-general-chapter synthesis`
-> `monitor-vs-audit evaluation`
-> `engineering eligibility freeze`
-> `G2 engineering batch`
-> `G3 engineering batch`
-> `G4 engineering batch`
-> `G5 engineering batch`
-> `engineering-general-chapter synthesis`.

No active B is permitted before the full 84-trajectory natural block and the independent audit/monitor-evaluation block are frozen.

This sequencing prevents engineering intervention results from influencing later natural groups.

## 2. Natural experimental block

G1 remains the immutable discovery/calibration reference group.

G2-G5 are four prospective replication groups:

- G2: 21 natural first attempts;
- G3: 21 natural first attempts;
- G4: 21 natural first attempts;
- G5: 21 natural first attempts.

Prospective total:

`4 × 21 = 84 natural first attempts`.

Publication-facing total with G1:

`21 + 84 = 105 natural trajectories`.

The four prospective groups use the same frozen task families, system conditions, common horizon, provider/retry policy, monitor version, checkpoint version, and evidence schema unless a safety-critical execution defect requires a prospectively documented stop-and-version change before a whole later group.

No result-conditioned tuning is allowed.

## 3. Monitor and checkpoint infrastructure during natural A

The engineering infrastructure is present during every natural A only as passive evidence infrastructure.

Allowed during A:

- native event capture;
- protocol/message/call capture;
- carrier capture;
- checkout/state hashing;
- passive checkpoint recording;
- structural monitor computation;
- warning/candidate generation;
- immutable monitor-output freeze.

Forbidden during A:

- repair action;
- adaptive prompt/action changes from monitor output;
- semantic CPR labels injected into the subject;
- monitor-driven task termination other than pre-frozen safety/runtime limits;
- B branch launch;
- semantic-audit feedback into monitor rules.

The monitor must use one frozen prospective version across G2-G5 for the primary benchmark population.

If that version changes after G2 begins, the changed version forms a new benchmark stratum and cannot be silently pooled with the earlier version.

---

## 4. Evidence-channel separation

Every prospective natural cell produces at least two logically separate evidence products.

### 4.1 Audit raw bundle

The audit raw bundle may contain:

- native messages/events;
- protocol traffic;
- tool/resource calls;
- repository/file state;
- retrieval/memory/compression carriers;
- checkpoint metadata necessary to reconstruct the recorded route;
- termination/return-code evidence;
- immutable hashes/provenance.

It must exclude:

- monitor warning labels;
- monitor candidate labels;
- monitor confidence/severity;
- repair-package labels;
- monitor CPR predictions;
- monitor-derived “ground truth” annotations.

### 4.2 Monitor runtime bundle

The monitor runtime bundle contains:

- monitor version/hash;
- observed surfaces;
- warnings;
- candidates;
- structural signature type;
- detected source/carrier/decision references where available;
- warning sequence/time;
- monitor coverage/self-boundary evidence;
- package candidates generated prospectively, if the monitor architecture produces them.

The monitor runtime bundle must not contain post-hoc semantic-audit verdicts.

### 4.3 Evaluation join

The two channels may be joined only after:

1. all 84 natural A trajectories are frozen;
2. monitor outputs are frozen;
3. the independent semantic audit reference set is frozen;
4. the matching/evaluation rules are frozen.

## 5. Independent full semantic audit

The complete semantic audit is a post-hoc reference adjudication layer.

It reads the audit raw bundle, not the monitor runtime bundle.

The audit must remain monitor-blind until its reference records are sealed.

For each supported target structure, the reference audit records where observable:

- group/cell;
- complete route;
- source;
- carrier;
- semantic before;
- semantic after;
- descendant relation;
- reader/adopter;
- decision/action linkage;
- consequence;
- first observable point;
- first consequence point;
- C/P/R interpretation;
- cross-penetration path;
- closure state;
- negative-boundary status;
- evidence-surface availability.

The audit must also record explicit negative structures and NOT_ESTABLISHED relations.

The reference audit is not a claim of universal ground truth. It is the within-study post-hoc reference adjudication used for monitor evaluation.

## 7. Monitor benchmark population

Primary prospective monitor benchmark:

`G2-G5 = 84 natural trajectories`.

The benchmark compares prospectively frozen monitor outputs against the independently frozen semantic-audit reference set.

All performance claims are labeled:

> **within-study prospective monitoring performance**

They apply only to the frozen systems, tasks, model/provider configuration, monitor version, observation surfaces, and groups in this study.

They are not product-SLA claims and are not universal AI-system accuracy estimates.

### 8.3 Localization level

- source localization accuracy;
- carrier localization accuracy;
- consumer localization accuracy where observable;
- decision-link localization accuracy;
- first-observable-point distance;
- first-consequence lead distance.

### 8.4 Lineage level

- lineage node coverage;
- lineage edge coverage;
- descendant-carrier coverage.

### 8.5 Observability level

Separate:

- end-to-end capture rate over the full audit reference set;
- conditional detector recall over audit structures whose required evidence surface was legally observable by the monitor.

This separates detector misses from evidence-surface unavailability.

## 9. Matching rules

Monitor and audit outputs are not matched by free-form human preference.

A prospectively frozen matching protocol defines:

- group/cell identity;
- structural-signature compatibility;
- source/hash match where available;
- carrier identity/compatibility;
- allowed sequence/event window;
- lineage overlap threshold where applicable;
- exact definitions for SUPPORTED_MATCH, PARTIAL_LOCALIZATION, UNSUPPORTED_WARNING, AUDIT_REJECTED_WARNING, UNOBSERVABLE_REFERENCE, and MISS.

Changing matching rules after seeing aggregate performance requires a new evaluation version and cannot replace the frozen primary result.

## 11. Engineering eligibility gate

Only after the natural block, semantic reference audit, experimental synthesis, and primary monitor evaluation are frozen does the repair phase open.

All 84 G2-G5 natural trajectories enter engineering eligibility accounting.

Eligibility is based on the prospectively generated monitor/localization/checkpoint/package evidence and native-preservation rules.

The independent semantic audit may evaluate monitor/package quality, but it may not create a new primary repair candidate for a trajectory the monitor failed to localize.

This protects the end-to-end engineering claim:

`monitor -> localization -> eligibility -> repair`.

Audit-assisted exploratory repairs, if ever run, must be a separately labeled secondary experiment and may not be pooled with the primary engineering result.

5. G4 engineering batch;
6. freeze G4 B/post-repair evidence and audit;

Within each batch:

- only legally eligible cells run B;
- maximum one B per eligible cell;
- frozen same parent;
- frozen package;
- repair executor exits after one application;
- monitor remains watch-only;
- no second automatic repair.

A repair-layer implementation defect discovered in an earlier engineering batch may be fixed prospectively before a later engineering batch only with an explicit engineering-version boundary. Natural A evidence remains untouched.
