# Jump Position under Reality Bias v4

Date: 2026-09-16

Jump is the observable realization layer between latent Escape Propensity and downstream system dynamics.

Jump detection should prefer recorded behavior/state transitions over reconstruction of full reasoning.

Jump detection and Jump explanation remain separate:

- detection localizes the transition;
- explanation tests which controlled variables alter its incidence or downstream consequence.

A structural Jump candidate is not automatically semantic C/P/R.
