## RA04 direct reduction tests

### Propagation versus C

- e-commerce discovery-history functional semantic continuation: **9/9**;
- continuation is broader than Dynamic C;
- C requires increased operational/epistemic permission without commensurate independent evidence.

Therefore:

`propagation != authority migration`.

### Collaboration versus P

- P is defined by goal/authorization/process alignment, not Agent count;
- earlier first-new-Agent P proxy captured only **4/13** later P-supported trajectories.

Therefore:

`collaboration/activity != scope-permission expansion`.

### Reopen versus R

R requires retrospective reactivation that generates a new C/P event.

Therefore:

`retrieval/reopen != retrospective-generative permission`.

### Persistence versus inertia

In canonical R5:

- **25/29** are better explained by healthy/ordinary alternatives;
- **4/29** show stronger case-level structures.

Therefore:

`persistence != System Inertia`.
