## Foundational Attack 01 — structural omission

Frozen calibration on the same 90 held-out natural trajectories:

- B2 union capture: **10/13 = 76.92%**;
- conditional miss: **3/13 = 23.08%**;
- P capture: **4/13**;
- R capture: **9/12**;
- broader triage post-late evidence-preservation proxy: **13/13**.

Conclusion:

> **Structural scouting is a localization layer, not the semantic verdict layer.**

## Foundational Attack 02 — capability absorption

The manuscript must not defend itself by predicting that future LLMs will continue making today's mistakes.

Instead:

> **Some manifestations may decline as models improve. Model consolidation does not, by itself, eliminate independently governed evidence, state, authorization or action boundaries.**

Therefore:

> **Protocol location can change; boundary integrity does not disappear merely because model capability increases.**

Implementation path may evolve through:

`external monitor -> middleware -> embedded protocol -> model-native integrity`.

The long-term research object is not “small Agents need an external monitor”; it is integrity of Process Reality across independently governed system boundaries.
