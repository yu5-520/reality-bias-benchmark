## Desk-review test

Before submission, a reader who sees only:

- title;
- abstract;
- Figure 1;
- first 600-800 words

must be able to answer:

1. What new scientific object is being studied?
2. Why do endpoint metrics miss it?
3. What evidence makes it more than a conceptual framework?
4. What intervention/control result makes it actionable?
5. Why does it matter beyond the exact ecommerce discovery case?

If any answer requires reading the Supplement or repository first, the main manuscript is not ready.
