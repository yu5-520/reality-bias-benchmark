## Reproducibility principle

The paper, Supplement and repository have distinct roles:

`Paper = sufficient scientific argument`

`Supplement = extended evidence accounting`

`Repository = complete traceability and machine validation`

The repository is not used to make the manuscript's scientific claim larger than the text supports.
