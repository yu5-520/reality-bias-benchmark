# NMI-P4 Foundational Attack 02 — Capability Absorption and System-Boundary Persistence

Date: 2026-09-20  
Status: **THEORY BOUNDARY HARDENED / OUTLOOK ONLY / NO FUTURE-PERFORMANCE CLAIM**

## Attack question

> If future foundation models become sufficiently capable and consolidate planning, memory, tool use, monitoring and repair into one large system, does Process Reality become a temporary problem that the model eventually absorbs?

This attack targets the long-term existence of the research object rather than the performance of the current experiment.

## 1. What stronger models may legitimately remove

The paper does not require today's observable manifestations to persist unchanged.

Capability scaling may reduce:

- obvious state misreading;
- forgetting of explicit constraints;
- redundant Agent invocation;
- low-quality decomposition;
- crude provisional/fact confusion;
- some unnecessary collaboration expansion.

These are capability-sensitive manifestations and should not be treated as permanent invariants.

## 2. What capability alone does not establish

A model can reason better about evidence, but reasoning capability is not itself:

- new external evidence;
- source provenance;
- target-system authorization;
- validity duration;
- write permission;
- re-entry permission;
- independent confirmation.

The opening stock example therefore has a future-proof logical core:

`preliminary / unreconciled`

does not become:

`externally reconciled`

merely because the reasoning system is more capable.

The model may acquire new evidence through an authorized interface, but that is a change in the evidence/authority state, not a consequence of intelligence alone.

## 3. Consolidation does not eliminate system boundaries

A future highly consolidated AI system may absorb many components that are presently separate:

`planner + memory + RAG + tools + verifier + monitor + repair`.

That does not imply that independently governed reality domains disappear.

A consolidated system may still exchange representations with:

- humans;
- databases;
- enterprise systems;
- organizations;
- physical systems;
- external services;
- other AI systems.

Whenever a representation crosses such a boundary, the receiving domain still has to determine whether that representation may be:

- trusted;
- acted upon;
- persisted;
- granted write authority;
- treated as current;
- reactivated later.

The long-term object is therefore not the existence of many small Agents. It is the integrity of process reality across independently governed state/evidence/authority boundaries.

## 4. Architectural-location invariant

The protocol may move.

It may be:

1. an external monitor;
2. middleware;
3. embedded in an application runtime;
4. model-native;
5. enforced by another large integrity/governance system.

The architectural placement is contingent.

The boundary condition is not.

Canonical formulation:

> **Protocol location can change; boundary integrity does not disappear merely because model capability increases.**

Related invariants:

> **semantic transfer != authority transfer**

> **retrieval != re-entry authority**

> **cross-system output != target-system commit authority**

## 5. Relation to the first foundational attack

Foundational Attack 01 showed:

- the narrow structural selector can miss later semantic findings;
- broader structural triage still preserved relevant post-late evidence in 13/13 later P/R-supported trajectories;
- structural observability and semantic adjudication should therefore be separated.

Attack 02 extends that separation through time.

Today:

`External structural observer -> semantic monitor -> bounded repair`

Possible future:

`Embedded/model-native monitor -> protocol gate -> model-native or external repair`

The implementation can be absorbed while the monitored integrity condition remains.

## 6. Monitor + Repair architecture

The first attack and R7 repair evidence jointly motivate a future deployment pattern:

`Existing intelligent system`
-> `Process Reality Monitor`
-> `semantic lineage / affected closure`
-> `Repair Authority Gate`
-> `Repair Agent`
-> `selective reopen/recompute`
-> `re-entry watch`

The monitor should not automatically obtain broad write authority.

The repair agent should be authorized only for:

- the target semantic lineage;
- the evidence-supported affected closure;
- the permitted repair operation.

Otherwise the repair subsystem can itself generate a new P-style scope expansion.

## 7. Theoretical consequence

Multi-Agent interaction is retained as the experimental realization of the first paper, not the upper boundary of the theory.

The broader outlook is:

> **Process Reality Across Intelligent System Boundaries**

The first paper does not experimentally establish universal inter-system behaviour. It establishes a mechanism in interacting AI trajectories and identifies system-boundary protocol integrity as the longer-term research direction.

## 8. Claim boundary

This foundational attack does **not** establish:

- that Reality Bias will persist at the same frequency in future models;
- that future giant models cannot reduce current failure modes;
- that an external monitor will remain necessary;
- that a model-native protocol will have the same implementation;
- that inter-system Process Reality has already been experimentally validated across arbitrary systems.

It establishes the narrower conceptual boundary:

> Future capability improvement can change the manifestation and placement of Process Reality controls without making evidence, authorization, validity and cross-system state boundaries logically identical to model capability.

## Verdict

Attack:

**“Future LLMs may absorb the problem and make the framework obsolete.”**

Verdict:

**THE CURRENT IMPLEMENTATION MAY BE ABSORBED; THE THEORY SHOULD NOT BE BOUND TO THE IMPLEMENTATION.**

The paper should therefore avoid claiming that today's external monitor or multi-Agent topology is permanent.

It should instead define Process Reality as an integrity problem that can be externally monitored, embedded or model-native, while keeping its empirical claims inside the studied multi-Agent setting.
