# NMI-P7 Manual Submission Fields v1

Date: 2026-09-21  
Status: **MANUAL METADATA REQUIRED BEFORE PORTAL SUBMISSION**

P7 intentionally does not invent author or institutional metadata.

The following fields must be supplied by the human author during P8 assembly:

- legal author name exactly as it should appear in publication;
- affiliation(s);
- corresponding-author email;
- ORCID, if used;
- postal address if requested by the portal;
- competing-interest declaration;
- funding declaration;
- author-contribution statement where applicable;
- acknowledgements, if any;
- final repository/archive URL or DOI once an immutable public archive is actually created;
- cover-letter signature identity.

These are submission metadata, not scientific evidence. Their absence does not authorize guessing from GitHub usernames, account names or prior chat context.
