# Nature Machine Intelligence — P8 Live Submission Requirements Snapshot

Revalidated: 2026-09-21  
Status: **LIVE OFFICIAL-SOURCE REVALIDATION FOR INITIAL SUBMISSION**

This file supersedes older local requirement snapshots where the live journal pages differ.

## Current Article format

Official current Content Types page:

- main text: up to **3,500 words**, excluding abstract, Methods, references and figure legends;
- abstract: up to **150 words**, unreferenced;
- display items: up to **6** figures and/or tables;
- section order: unheaded Introduction -> Results -> Discussion -> Methods;
- Results and Methods use topical subheadings;
- Discussion has no subheadings;
- references: typically recommended up to **50**;
- Supplementary Information may accompany an Article.

Official source:
https://www.nature.com/natmachintell/content

## Initial-submission file format

Initial submission does not require special journal styling if the study is suitable for editorial assessment and peer review.

Accepted initial forms:

- PDF;
- Word;
- TeX/LaTeX with compiled PDF.

Official source:
https://www.nature.com/natmachintell/submission-guidelines/initial-formatting

## Required submission materials and author identity

The current Preparing your material page lists:

- manuscript file, including Methods and Figures;
- cover letter;
- Supplementary Information if applicable.

The manuscript file must contain the names and affiliations of all authors **unless double-anonymized peer review is chosen**. Under double-anonymized review, author/affiliation/contact information belongs in the cover letter instead.

The same page states that LLMs do not meet authorship criteria and that LLM use should be documented in Methods or a suitable alternative section.

Official source:
https://www.nature.com/natmachintell/submission-guidelines/preparing-your-submission

## Cover-letter disclosures

The current Preparing your material page asks the cover letter to:

- explain importance and fit for the broad Nature Machine Intelligence readership;
- disclose related manuscripts under consideration or in press;
- state whether the authors have had prior discussions with a Nature Machine Intelligence editor;
- carry author affiliation/contact details if double-anonymized review is selected.

Reviewer recommendations/exclusions are optional.

Official source:
https://www.nature.com/natmachintell/submission-guidelines/preparing-your-submission

## Double-anonymized review

Nature Machine Intelligence currently offers double-anonymized peer review. Authors selecting it are responsible for anonymizing the manuscript and selecting the relevant option in the submission system.

Official source:
https://www.nature.com/natmachintell/submission-guidelines/dapr

## Competing interests

The current Nature Machine Intelligence policy requires authors to disclose relevant financial and non-financial competing interests during submission. The corresponding author submits the declaration on behalf of all authors. The published article also carries a competing-interests statement.

For double-anonymized review, the submission system receives a minimal statement, while the full disclosure is included in the cover letter.

Official source:
https://www.nature.com/natmachintell/editorial-policies/competing-interests

## Data and code availability

The journal requires a Data Availability section. Central custom code must be available to editors/referees on request, and public release enabling repetition is described as best practice for publication. The current manuscript already contains Data Availability and Code Availability sections.

Official journal guide:
https://www.nature.com/documents/natmachintell-brief-submission-guide.pdf

## ORCID timing

The current submission-guidelines landing page states that corresponding authors of accepted papers are requested to link ORCID before final acceptance. ORCID is therefore not treated here as an automatic blocker to the initial scientific preflight, although it can be supplied during submission.

Official source:
https://www.nature.com/natmachintell/submission-guidelines

## Important version conflict resolved

The older 2018 brief submission guide states an Article main-text limit of 3,000 words. The current live Content Types page states **3,500 words**. P8 uses the current live journal page as the controlling initial-submission limit.

## P8 implication for this repository

Automated scientific/editorial checks pass, but the package is **not portal-ready** until the author chooses:

- standard author-visible review; or
- double-anonymized review,

and supplies the corresponding verified author/affiliation/contact/declaration fields.

No author identity or declaration is inferred from the GitHub account, chat account, repository metadata or prior conversations.
