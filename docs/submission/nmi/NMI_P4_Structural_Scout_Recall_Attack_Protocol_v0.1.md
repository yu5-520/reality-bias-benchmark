# NMI-P4 Attack Protocol v0.1 — Structural Scout Recall / Semantic Blind-Spot Test

Date: 2026-09-20  
Status: **AUTHORIZED OFFLINE ATTACK / FROZEN EVIDENCE ONLY**

## Attack

> How do we know that structural scouting did not omit semantically important problem information? If it did, what is the miss rate?

## Evidence universe

The attack is restricted to the only directly comparable frozen population:

- 90 held-out natural trajectories (Finance 30, Supply Chain 30, Software Engineering 30);
- frozen structural triage generated from those same 90 trajectories;
- later R8 trajectory-first full semantic adjudications for those same trajectories.

No R5/R7 trajectories enter the recall denominator because they were not part of the original 90-trajectory structural triage population.

## Core distinction

The historical triage compressed:

- 2,127 structural repair-anchor candidate rows
- to 167 selected localized-audit cases
- across all 90 trajectories.

The 167/2,127 = 7.85% figure is **candidate-surface compression**, not semantic recall and not a 92.15% miss rate.

The attack must estimate semantic coverage against the later full-trajectory R8 adjudication.

## Required metrics

1. **Exact-anchor recall** — a later supported semantic episode directly intersects a selected triage source anchor.
2. **Lineage-reachable recall** — not exact, but the selected anchor's recorded upstream/downstream structural evidence intersects the later semantic episode.
3. **Full-trajectory-only rate** — semantic episode was found by R8 but is not traceably covered by any selected scout anchor.
4. **Miss rate** — 1 - (exact + lineage-reachable recall), using supported semantic episodes as denominator.
5. **Dimension calibration** — separate coverage for C, P and R.
6. **Role ablation** — coverage contributed by FORMATION_ANCHOR, PROPAGATION_ANCHOR and AUTHORITY_REVIEW_ANCHOR.
7. **Compression/recall pair** — report 7.85% candidate-surface retention together with semantic recall; never substitute one for the other.

## Important guard

Trajectory-level recall is not sufficient: every natural trajectory already received structural anchors by construction, so “same trajectory contains an anchor” is uninformative.

The meaningful denominator is the later R8-supported semantic episode/dimension evidence.

## Scientific interpretation

If recall is high:
- structural scouting is an efficient localization layer.

If recall is materially below 100%:
- structural scouting is a prioritization layer, not a semantic detector;
- the miss pattern explains why R8 requires full-trajectory semantic reconstruction;
- R5/R6/R7 mechanism cases must be described as **scout-qualified mechanism sets**, not an exhaustive catalogue of all Process Reality mechanisms.

No possible result is allowed to retroactively mutate the frozen natural evidence.
