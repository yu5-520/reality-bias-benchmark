# Figure 3 — Functional Semantic Lineage

### Editorial job

Explain how semantic influence survives even when the original wording disappears.

This is the paper's separation from ordinary message propagation and event provenance.

### Panel A — Propositional vs functional lineage

Propositional lineage:

`same proposition / paraphrase`.

Functional semantic lineage:

`constraint`
`causal role`
`decision implication`
`action implication`
`operational reuse`.

### Panel B — Semantic carrier substitution

`source proposition`
->
`transformed risk / constraint`
->
`shared state`
->
`plan / decision`
->
`action`.

The source text may disappear while its decision function remains active.

### Panel C — Healthy vs penetrating lineage

Healthy:

`provisional source`
->
transformation
->
uncertainty preserved
->
conditional action.

Penetration:

`provisional source`
->
transformation
->
uncertainty detaches
->
descendant becomes operational premise.

### Panel D — Audit distinction

`propagation != permission penetration`.

`descendant persistence != Dynamic C`.

Functional continuation is a broader phenomenon than C.
