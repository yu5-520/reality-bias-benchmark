# Nature Machine Intelligence — Official Submission Requirements Snapshot

Verified: 2026-09-20  
Use: **submission-engineering constraint only; re-check immediately before submission**

Official journal: Nature Machine Intelligence

## Article format

Official Content Types page states that an Article is a substantial novel research study with a complex story often involving several techniques or approaches.

Current Article constraints:

- main text: up to **3,500 words**, excluding abstract, Methods, references and figure legends;
- abstract: up to **150 words**, unreferenced;
- display items: up to **6** figures and/or tables;
- structure:
  - Introduction without heading;
  - Results;
  - Discussion;
  - Methods;
- Results and Methods should use topical subheadings;
- Discussion should not contain subheadings;
- references: typically recommended up to **50**;
- supplementary information may accompany the Article.

Official source:
- https://www.nature.com/natmachintell/content

## Initial submission format

The journal states that initial submission does not need special formatting as long as it is suitable for editorial assessment and peer review.

Accepted initial forms include:

- PDF;
- Word;
- TeX/LaTeX with compiled PDF.

Official source:
- https://www.nature.com/natmachintell/submission-guidelines/initial-formatting

## Editorial screening criteria

The journal states that editors decide whether to send a paper for peer review based on:

- degree to which it advances understanding of the field;
- soundness of conclusions;
- extent to which evidence/data/analyses support the conclusions;
- wide relevance to the journal readership.

Official source:
- https://www.nature.com/natmachintell/submission-guidelines/editorial-process

## Required submission materials

The preparing-submission page lists:

- manuscript file;
- cover letter;
- Supplementary Information if applicable.

It also states that LLMs do not satisfy authorship criteria and that LLM use should be properly documented in the Methods section (or suitable alternative where Methods is unavailable).

Official source:
- https://www.nature.com/natmachintell/submission-guidelines/preparing-your-submission

## Data / code availability

The journal's submission guide requires a Data Availability section and requires availability statements for central custom code. Central custom code must be available to editors/referees upon request, and public release enabling repetition of results is described as best practice at publication.

Official source:
- https://www.nature.com/documents/natmachintell-brief-submission-guide.pdf

## Local submission targets

For this paper:

- target main text: **3,200-3,350 words**, leaving revision margin under 3,500;
- target abstract: **135-150 words**;
- target main display items: **5**, leaving one display slot uncommitted;
- Methods: detailed enough to reproduce evidence geometry, freezing, trajectory reconstruction and intervention logic;
- Supplement: extended trajectory tables, audit accounting, censoring, provenance and reflexive S1;
- Repository: raw evidence / manifests / hashes / validators / code.
