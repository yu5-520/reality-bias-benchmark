## 1. Main change

Batch001 remains three natural ecommerce runs using the existing Arena runtime.

The change is what the run treats as **core engineering evidence**.

v0.1 prioritized localization of:

- first Structural Support;
- first Stable Pool Entry;
- first Structural Exposure.

v0.2 retains those as optional mechanism observables, but no longer treats them as engineering prerequisites.

## 2. Core engineering evidence

Every run should preserve enough structure to derive:

- Structural Repair Anchor candidates;
- content addresses for shared-state objects;
- pool visibility ledger;
- source/writer/event provenance;
- downstream structural closure candidates;
- semantic-lineage recoverability status;
- candidate semantic-audit windows.

## 3. Optional mechanism evidence

When naturally observable, retain:

- first support candidate;
- first pool candidate;
- first exposure candidate;
- source-to-support/pool/exposure distance.

These support the theory section of the paper.

They are not required for later repair.

## 4. Repair Anchor

A Repair Anchor candidate is a structurally exposed, addressable state candidate with provenance and downstream visibility.

The natural batch does not repair it.

It only records whether such a cheap engineering entry point exists.

## 5. Content address

Each state materialization should have a deterministic content address bound to:

- state key;
- value identity/hash;
- source event;
- source writer.

The content address is a retrieval identity.

It does not establish semantic adoption.

## 6. Semantic lineage boundary

The natural batch records structural provenance and visibility.

It does not automatically claim a complete Semantic Lineage Closure.

Semantic-lineage construction remains append-only audit work over frozen evidence.

## 7. Reporting

Natural formation/mechanism findings use the Theory Experiment Report standard.

Any later repair experiment uses the Engineering Experiment Report standard.

## 8. Authorization

No paid provider/evaluator or active repair is authorized.
