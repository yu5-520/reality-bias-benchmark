## 1. Paper thesis

The first paper studies **Process Reality Fidelity** in multi-Agent systems.

The paper does not define success by terminal task correctness alone. It asks how information acquires process authority, enters system history, becomes inherited inertia, responds to minimal perturbation, and can be localized/repaired without suppressing unrelated process freedom.

## 2. Four contribution layers

### Contribution 1 — Phenomenon

Terminally similar multi-Agent runs can contain materially different realized process histories.

### Contribution 2 — Mechanism

A local Jump/Reality-Authority transition can enter source-backed carriers and influence later process structure as inherited system inertia.

### Contribution 3 — Identification

R6 separates:

- direct/local perturbation response;
- natural process variability;
- carrier/read/adoption/inheritance/propagation evidence;
- intervention-related post-consumption inertia transition;
- target specificity against ordinary factual uncertainty.

### Contribution 4 — Localized solution

R7 tests whether an identified risk-bearing carrier/closure can be repaired locally while preserving unrelated process structure, motivating a lightweight content-addressed runtime Process Integrity Protocol.

CPR semantic identity remains separately adjudicated rather than inferred from structural difference.

## 3. Evidence architecture

```text
raw evidence
  -> structural Jump/lineage
  -> local response
  -> R6 carrier/inertia identification
  -> natural-variability comparison
  -> R6-D target specificity
  -> R7 localized risk-control/recovery
  -> R8 CPR adjudication
  -> terminal outcome reported separately
```

## 4. R5 role

R5 is a bounded experimental probe.

It withdraws acquired factual authority once without supplying a replacement answer, persistent mutation or topology instruction.

R5 may establish direct perturbability/path response. It does not alone establish long-range inertia change, target specificity, semantic bias or controllability.

## 5. R6 role

R6 is the central mechanism-identification layer.

### R6-A Natural baseline

Estimate how much process variation exists naturally from repeated continuations.

### R6-B Carrier identification

Trace source-backed carriers from prior state to later read/use/state/action/descendant evidence.

### R6-C Intervention-related inertia transition

Ask whether post-consumption structure differs from natural variability rather than merely whether one A/B trajectory differs.

### R6-D Target specificity

Use S0/S1/S2 to distinguish generic uncertainty response from J0-targeted inertia response.

## 6. Existing frozen evidence

Current R5-MID evidence supports:

- a natural source-backed J0;
- one-shot intervention integrity;
- observable local/direct structural response;
- natural downstream inertia candidates, especially the extended A2 continuation;
- substantial natural variation across repeated natural continuations;
- matched downstream structural differences;
- similar core terminal decisions despite process differences.

Current evidence does not yet establish:

- a stable intervention effect beyond natural variability;
- repeatable post-consumption carrier-mediated condition differences;
- S2 vs S1 target specificity;
- semantic C/P/R identity;
- scientific R7 recovery efficacy.

## 7. Exact-source specificity

The exact frozen parent contains no second non-J0 top-level fact-status state. Therefore the prospective specificity design uses atomic factual information.

Frozen prospective targets:

- S1 ordinary fact: `public_context.products.C.gross_margin_pct = 35`;
- S2 escape-derived target: `shared_state.inventory_stockout_assessment_v1.A.preliminary_stock = 1520`.

The S2 signal originated as `preliminary_unreconciled` and later entered a state object carrying `fact` authority at J0.

Both S1/S2 preserve original values and add the same one-shot `unconfirmed` annotation.

## 8. CPR claim boundary

The paper must not infer CPR from structure alone.

For C, establish unsupported/weak support -> stronger inheritable factual authority plus downstream use consistent with that stronger authority.

For P, establish unsupported/unauthorized expansion plus material process change.

For R, establish prior deviation + valid challenge/correction opportunity + source-linked persistence/regeneration + absence of sufficient new evidence.

## 9. R7 scientific solution

R7 asks whether mechanism knowledge can be operationalized.

The desired scientific result is not simply “recovery worked.” It is:

> the identified risk-bearing closure can be localized/revised with lower structural destruction than broader forcing/rerun while preserving unrelated process freedom.

Report risk-control and preservation outcomes together.

## 10. R7 engineering implication

The scientific mechanism motivates a runtime layer with these design targets:

- lightweight;
- pluggable;
- non-invasive/passive by default;
- protocol-agnostic;
- real-time;
- content-addressed;
- lineage-aware;
- locally recoverable;
- auditable/reversible.

The layer does not need to replace Agent, MCP, A2A or orchestration interfaces.

Potential minimal runtime events:

- MessageEvent;
- StateEvent;
- InvocationEvent;
- EvidenceSourceEvent;
- RevisionEvent.

The engineering lifecycle is:

`observe -> address -> trace -> localize -> repair if authorized -> resume -> verify`

## 11. Why this differs from ordinary Agent logging

Ordinary logs mainly support retrospective event search.

The proposed integrity layer aims to maintain a live process index capable of answering:

- where a state came from;
- which Agents consumed it;
- which descendants inherited it;
- what the affected closure is;
- which revision replaced it;
- whether old lineage re-entered after repair.

This is the practical value of real-time content addressing and lineage.

## 12. Paper narrative

Preferred narrative order:

1. terminal outcome is insufficient to characterize multi-Agent process reality;
2. natural trajectories reveal local Jumps and inherited structure;
3. a minimal R5 perturbation establishes local sensitivity without prescribing a replacement solution;
4. R6 separates local response, natural variability, carriers, inertia transition and target specificity;
5. R7 tests whether identified risk-bearing structure enables localized recovery;
6. R8 performs semantic CPR adjudication after structural freeze;
7. R9 remains external replication, not a compute arms race.

## 13. Engineering content proportion

The first paper should include the R7 engineering solution as a mechanism-derived method contribution, but it should not become a product brochure.

The paper needs to show:

- the process objects are operationally observable;
- localization is machine-readable/content-addressable;
- local recovery can be represented/executed;
- unaffected structure can be preserved and measured;
- the runtime layer can remain passive when recovery is disabled.

Full production adapters, distributed stores and enterprise UI are future work.

## 14. First-paper nonclaims

Do not claim without evidence:

- stable monotonic treatment effects;
- that one A/B difference exceeds natural variability;
- that reachability implies semantic adoption;
- that termination proves extinction;
- that S1 should have zero effect;
- that target specificity establishes CPR;
- universal control/recovery efficacy;
- cross-model/domain generality from one environment;
- production-grade safety guarantees.
