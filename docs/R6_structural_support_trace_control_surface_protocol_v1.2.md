# R6 Structural Support / Trace / Control-Surface Protocol v1.2

Date: 2026-09-19
Status: FORWARD v5.4
Predecessor: v1.1

R6 is passive and consumes a canonical evidence pair:

`N0 frozen natural continuation + R5-I frozen one-shot continuation`.

R6 derives:

- source/root;
- local semantic response;
- carrier/support;
- downstream read;
- semantic adoption;
- decision/action dependence;
- post-stimulus persistence;
- affected lineage;
- candidate repair surface;
- lineage completeness status.

R6 does not require a new provider run and does not require repeated intervention reproduction.

Natural and R5 paths may differ because the model is stochastic. R6 compares realized structures, not exact token/path equality.

R7 entry depends on complete/repairable affected lineage, not recurrence frequency.
