# Reality Bias Research Plan v5.1

Date: 2026-09-18  
Status: FORWARD REFINEMENT / PAPER-LAYER SEPARATION / NO SCIENTIFIC RUN AUTHORIZATION  
Predecessor: `docs/R_Plan_v5.0.md`

## 1. Main refinement

v5.1 does not add a new R stage.

It changes the relationship between mechanism research and engineering control.

The system no longer treats localization of the globally first Structural Support / Pool Entry as an engineering prerequisite.

## 2. Theory experiment line

R2-R6 theory work asks:

- where unstable information appears;
- how semantic transformations occur;
- how Agents adopt/reframe descendants;
- whether stable shared pools exist;
- whether semantic descendants persist;
- what source/pool decoupling is supported.

First support / first pool / first exposure remain optional mechanism observables when evidence permits.

## 3. Engineering experiment line

Engineering work asks:

- can a cheap Structural Repair Anchor be scouted;
- can the target semantic object be content-addressed;
- can the complete relevant Semantic Lineage Closure be reconstructed;
- can unrelated semantic branches be excluded;
- can a Lineage Completeness Gate block guessing;
- can the bounded RepairClosure be repaired/recomputed;
- can unrelated structure remain preserved.

## 4. R5

R5 remains Structural Scouting + optional Driver Probe.

For engineering use, its main output is a candidate Repair Anchor rather than a claim about semantic origin.

## 5. R6

R6 becomes the semantic-lineage localization layer:

`Repair Anchor -> Content Address -> Semantic Lineage Closure -> Completeness Gate -> Repair Surface`

R6 may trace to the original source when relevant.

It does not scan unrelated task semantics.

## 6. R7

R7 consumes a complete or explicitly audit-only Semantic Repair Packet.

`LINEAGE_GAP` blocks automatic Repair Agent execution.

R7 tests targeted repair, selective recomputation, old-lineage re-entry and preservation of unrelated semantics.

## 7. Fresh Whole-Process runs

Core collection should prioritize:

- shared-state identity/content address;
- provenance;
- visibility/consumer opportunities;
- Repair Anchor candidates;
- relation evidence;
- downstream closure addressability;
- semantic-lineage recoverability.

First-node localization becomes optional mechanism analysis, not a prerequisite for the engineering protocol.

## 8. Reporting

Use separate report families:

- Theory Experiment Report;
- Engineering Experiment Report.

Future discussion is a third paper layer, not an experiment result.

## 9. Authorization

No provider/evaluator/repair execution is authorized by this plan.
