# Canonical Stochastic Realization Principle v1.0

Date: 2026-09-19

The first-paper experiment treats stochasticity as part of the scientific object.

1. Probability is sampled across natural trajectories in a frozen domain environment.
2. Once a trajectory is frozen, its realized structure is analyzed as realized evidence.
3. R5 applies one transient intervention once.
4. R6 observes frozen evidence offline.
5. R7 applies one persistent-semantic trajectory and one structured-repair trajectory.
6. Repeated same-parent sampling is supplementary robustness, not evidence admission.

Therefore:

`repetition may characterize local recurrence; it must not erase realized process structure`.
