# Process Reality v5 Optional Robustness Modules

Date: 2026-09-18  
Status: FORWARD EXPERIMENT-SIMPLIFICATION MAP

## 1. Principle

A robustness module is not deleted merely because it is no longer part of the default subject chain.

Historical modules remain available when a specific scientific question requires them.

## 2. Modules moved out of the default core

| Historical module | v5 status | Activate when |
| --- | --- | --- |
| S0/S1/S2 specificity | OPTIONAL ROBUSTNESS | testing response differences across preregistered target classes |
| S2/S3/S4 matched-stock controls | OPTIONAL ROBUSTNESS | testing target matching / ordinary-stock alternatives |
| R6-D Escape/J0 specificity | LEGACY ROBUSTNESS | reproducing/comparing historical target-specific claims |
| re-Jump count/distance | STRUCTURAL TELEMETRY | topology recurrence is directly relevant |
| R6-A natural baseline as separate batch | OPTIONAL | manipulation requires an independently sampled baseline |
| R6-B carrier-only batch | ANALYSIS VIEW | carrier/support evidence cannot be derived from the core run |
| R6-C intervention transition batch | OPTIONAL MANIPULATION | a driver/control hypothesis requires causal branch comparison |
| multiple semantic reviewers | APPEND-ONLY SUPPLEMENT | interpretation robustness is material |
| cross-model/domain replication | R9 SUPPLEMENT | external validity is the question |

## 3. What remains core

Core Whole-Process Run:

- natural process collection;
- raw evidence freeze;
- structural indexing;
- support/pool/exposure scouting;
- localized semantic audit;
- reusable evidence bundle.

Driver probes and recovery remain optional controlled extensions.

## 4. No evidence deletion

Moving a historical module out of the default chain does not weaken or erase its prior evidence.

Its result remains part of the historical evidence record and may still constrain future interpretation.

## 5. Anti-proliferation rule

Do not create a new mandatory substage merely because one analysis question appears.

Prefer:

1. reuse existing frozen evidence;
2. add an append-only analysis view;
3. activate an optional robustness module;
4. add a new manipulated subject phase only when the scientific question cannot be answered otherwise.
