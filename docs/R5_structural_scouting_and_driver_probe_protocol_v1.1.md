# R5 Structural Scouting and Driver-Probe Protocol v1.1

Date: 2026-09-19  
Status: FORWARD v5.3 / CASE-LEVEL PROBE / NO EXECUTION AUTHORIZATION  
Supersedes: `docs/R5_structural_scouting_and_driver_probe_protocol_v1.0.md`

## 1. Unit

R5 operates on a naturally realized source-bound case.

R5 does not estimate how often the phenomenon occurs in a domain.

## 2. Roles

1. Structural scouting/localization.
2. Minimal driver probing when justified.

A probe asks whether one local source-status change is followed by a local response in the realized continuation.

## 3. One-shot boundary

For the existing `fact -> unconfirmed` family:

- exact frozen parent;
- one direct exposure;
- zero reinjection;
- no persistent experiment-origin state mutation;
- full continuation recorded.

## 4. Handoff to R6

R5 hands R6:

- source identity;
- direct exposure;
- local response;
- candidate carrier;
- downstream event windows;
- frozen continuation.

Replicate-stable terminal behavior is not required before R6 can inspect the path.

## 5. Probability boundary

R5 does not re-estimate domain probability.

Repeated fixed-parent trials, if run, are supplementary local sensitivity only.

## 6. Authorization

No new provider/evaluator call is authorized.
