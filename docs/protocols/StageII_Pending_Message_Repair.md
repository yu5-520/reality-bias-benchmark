## Independent semantic review

historical and post-exit source observations, reconstructs source qualification,
representation changes, recorded use and observable consequences, and accounts
for old information authority, old task permission, historical re-entry,
transformed descendants and unrelated semantic progression.

`scripts/review_stage2_connected_repair.py` replays the reviewer's supplied
`queries` (`catalog`, `node`, `read`, `witness`) against those exact sources before
validating the supplied `report`. The host fixes reviewer identity and criteria;

produced reviewer submission is required; this is not an authentication service
