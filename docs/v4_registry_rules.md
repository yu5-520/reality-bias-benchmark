# v4 Registry Rules

Date: 2026-09-16

Experimental variables and measurement boundaries are versioned research interfaces.

- confirmatory variables must bind a registry version/hash;
- confirmatory target locations must bind a boundary registry version/hash where applicable;
- registries define interfaces, not empirical truth;
- adding a registry entry does not authorize a real run;
- deleting or mutating historical registry versions is prohibited once used by frozen evidence;
- exploratory variables may exist outside the registry but cannot be silently promoted into confirmatory claims.
