# Process Reality v5 Concept Mapping

Date: 2026-09-18  
Status: FORWARD TERMINOLOGY / LEGACY COMPATIBILITY MAP

## 1. New forward objects

| v5 object | Operational meaning | Must not imply |
| --- | --- | --- |
| Unstable Information | Information whose value/scope/authority/decision meaning remains unresolved across the process | false information |
| Escape Structure | Realized transmission structure through which information changes semantic form or system role | an Agent trait or special escape token |
| Semantic Transformation | Evidence-bound change from source proposition to a derived proposition/judgment/constraint/action | causal origin unless tested |
| Structural Support Point/Region | Candidate location where information/descendant obtains reusable structural support | semantic correctness |
| Stable Shared Information Pool | System-addressable state directly consumable by later Agents without renewed original relay | truth/confirmation |
| Structural Exposure State/Region | Support/propagation state sufficiently observable for structural scouting | first semantic change |
| Exposure Anchor | Selected machine-addressable anchor inside an exposure region | unique root cause |
| Trace Root | Upstream source/root used for lineage reconstruction | detection location |
| Intervention Surface | Explicit node/field/closure selected for repair/control | trace root or exposure anchor by definition |

## 2. Required separations

\`semantic genesis != structural support != stable-pool entry != structural exposure\`

\`Detection Surface != Trace Root != Intervention Surface\`

\`shared addressability != epistemic validity\`

\`literal persistence != semantic persistence\`

\`structural reachability != semantic adoption\`

## 4. Historical evidence rule

Legacy terms may appear unchanged in historical reports, manifests, schemas and frozen condition IDs.

Forward reports must distinguish:

- legacy identifier;
- current v5 interpretation;
- evidence status for the mapping.

No old artifact is rewritten merely to modernize vocabulary.
