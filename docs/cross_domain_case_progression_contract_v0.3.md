# Cross-Domain Case Progression Contract v0.3

Date: 2026-09-19
Status: FORWARD v5.4
Supersedes: `docs/cross_domain_case_progression_contract_v0.2.md`

A qualified case progresses by evidence completeness, not repeated stochastic reproduction.

```text
N0 frozen natural case
  -> R5-I one-shot continuation once
  -> freeze
  -> R6 passive structure + semantic audit
  -> lineage completeness gate
  -> if qualified:
       R7-P persistent semantic continuation once
       R7-S structured repair continuation once
  -> freeze
  -> R8 semantic closure
```

## Canonical provider geometry

- R5: 1 new trajectory per case;
- R6: 0;
- R7: 2 new trajectories per qualified case.

## Non-gates

The following do not gate progression:

- exact fixed-parent phenotype recurrence;
- synthetic-control agreement;
- replicate majority;
- repeated C1/C2/C3 reproduction.

Supplementary repeated sampling may characterize local recurrence/robustness only.
