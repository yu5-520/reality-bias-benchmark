## Core research position

The first paper is about **mechanism phenomena and underlying process logic**, not an engineering governance framework and not final-task accuracy as the primary unit.

```text
Natural trajectory
  -> observable local Jump
  -> inherited system inertia
  -> propagation / crossing / branching / re-entry
  -> repeated process patterns summarized as CPR
  -> prospective re-observation
  -> same-parent one-shot local perturbation
  -> free evolution
  -> compare recurrence / inertia / path reorganization / recovery
```

The central distinction is:

> **Outcome Validity != Process Reality Fidelity**

A task may end with a correct answer while its process contains unsupported promotion, scope expansion, inherited deviation or retrospective regeneration. A task may also end unsuccessfully while preserving evidence, uncertainty and authority boundaries. Final outcome is therefore a terminal observation, not the definition of Reality Bias.

## CPR position

CPR is a **process-dynamics taxonomy derived from repeated trajectory phenomena**, not a template that every run must satisfy.

- **C** — unsupported or weakly supported epistemic state becomes stronger, inheritable reality;
- **P** — goal/scope/focus/information/Agent surface expands beyond the supported or authorized process closure;
- **R** — prior C/P-derived state persists, regenerates, amplifies, launders or normalizes after a retrospective/challenge opportunity.

Recovery is not R-positive evidence.

A Jump is an observable event; inherited inertia is a mechanism; CPR is a dynamic-pattern classification; task outcome is a terminal state. These levels must not be collapsed.

## R2–R6: one trajectory research path

R2–R6 are not five sequential projects.

- **R2 — Emergence:** where/when a natural Jump appears and what changes;
- **R3 — Inheritance / Propagation:** how Jump-derived state enters context, messages, state and Agent paths and develops inertia;
- **R4 — Retrospective CPR Dynamics:** persistence, regeneration, amplification, normalization, correction and new Jump formation;
- **R5 — Causal Branch Operator:** freeze one natural node, perturb it once, remove the experimental variable, then compare downstream process dynamics;
- **R6 — Recovery / Residual / Recurrence:** natural or controlled recovery, residual descendants and later recurrence.

R2/R3/R4/R6 are measurement dimensions over a trajectory. R5 is a causal operator applied to a frozen node and compares those dimensions between matched continuations.

A complete experiment means the trajectory is observable across this research path; it does **not** mean every run must exhibit every phenomenon.

## Forward one-shot R5-MID invariant

For the intervention branch:

```text
same frozen parent as control
+ one local epistemic overlay at the selected Jump
+ exactly one direct experimental exposure
+ zero persistent shared-state mutation by the experiment
+ zero experimental reinjection after consumption
-> free multi-Agent evolution
```

Agent-generated uncertainty or later provisional state is allowed and is measured as endogenous downstream behavior.

The old persistent status-downgrade prepared bundle must not be reused for this forward protocol.

## Three primary mechanism observation families

1. **Jump recurrence / regeneration** — whether a downstream node naturally generates a descendant Jump after the direct experimental mark is gone.
2. **Inherited inertia** — whether the control path is preserved, deflected, broken or later reconverges after the local perturbation.
3. **Path-topology reorganization** — changes in observed path families, crossings, loops, re-entry, merge/reroute and role/responsibility activation.

Turn/call/token counts and final outcome remain diagnostics, not substitutes for these mechanism measurements.
