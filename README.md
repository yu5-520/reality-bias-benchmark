## Core research position

The first paper is about **mechanism phenomena and underlying process logic**, not final-task accuracy as the primary unit and not an architecture leaderboard.

```text
Natural trajectory
  -> observable local Jump
  -> inherited system inertia
  -> propagation / crossing / branching / re-entry
  -> one-shot local perturbation
  -> downstream path reorganization
  -> post-reorganization inertia transition
  -> structural inertia steering / localized recovery
  -> CPR semantic closure
```

The central distinction is:

> **Outcome Validity != Process Reality Fidelity**

A task may end with a correct answer while its process contains unsupported promotion, scope expansion, inherited deviation or retrospective regeneration. Final outcome is therefore a terminal observation, not the definition of Reality Bias.

## CPR position

CPR is a **process-dynamics taxonomy derived from repeated trajectory phenomena**, not a template every run must satisfy.

- **C** — unsupported or weakly supported epistemic state becomes stronger, inheritable reality;
- **P** — goal/scope/focus/information/Agent surface expands beyond the supported or authorized process closure and materially changes the path;
- **R** — prior C/P-derived state persists, regenerates, amplifies, launders or normalizes after a retrospective/challenge/reopen/correction opportunity.

Recovery is not R-positive evidence.

A Jump is an observable event; inherited inertia is a mechanism; CPR is a semantic process-dynamics classification; task outcome is a terminal state. These levels must not be collapsed.

## R2–R9 forward research roles

R numbers describe research roles/views; they do not require nine sequential subject experiments.

- **R2 — Emergence:** where and how a natural Jump appears;
- **R3 — Inheritance / Propagation:** how Jump-derived state enters downstream context, messages, state, invocations and paths;
- **R4 — Retrospective Dynamics:** persistence, regeneration, amplification, normalization, correction and return;
- **R5 — One-Shot Perturbability / Path Reorganization:** same frozen parent, one local perturbation, remove the experiment-origin mark, then compare free downstream topology;
- **R6 — Inertia Transition / Downstream Consequences:** what inertia persists, disappears, transfers, transforms, returns, reconstructs or reconverges after path change;
- **R7 — Structural Inertia Steering / Localized Recovery:** whether structural handling can change the direction, persistence, localization or recoverability of inherited inertia without prescribing terminal content;
- **R8 — CPR Semantic Closure / Evidence Freeze:** semantic adjudication only after structural evidence is frozen;
- **R9 — External Robustness / Replication:** additional reviewers, models, domains and independent implementations/laboratories.

## R5 one-shot invariant

For the intervention branch:

```text
same frozen parent as control
+ one local epistemic/state overlay at the selected Jump
+ exactly one direct experiment-origin exposure
+ zero persistent experiment-origin shared-state mutation
+ zero experimental reinjection after consumption
-> free multi-Agent evolution
```

R5 establishes perturbability/path reorganization where supported. It does **not** establish persistent inertia control.

The formal R5-MID batch and finalized v3 reports remain frozen and historically `NOT_ADJUDICATED` where the freeze contract says so.

## R6 — system inertia after path change

R6 retains the lower-level observations already present in the project but summarizes them as **post-reorganization system inertia**.

Relevant observations include descendant Jump continuation, same-family/transformed Jump, direct/indirect inheritance, transfer, delayed re-emergence, retrospective return, post-return inheritance, branch/merge/re-entry, cross-Agent continuation, replacement, reconstruction/hybridization and reconvergence.

Recovery, residual and recurrence are possible manifestations inside R6; they do not define the whole R6 object.

## R7 — three-condition mechanism design

R7 is broader than ALR. The preferred first-paper comparison is:

```text
                 Frozen J0
                    |
        +-----------+-----------+
        |           |           |
       C1          C2          C3
    One-shot    Persistent     ALR
      free        field      recovery
        |           |           |
        v           v           v
   endogenous   maintained   localized /
     inertia     persistence   structural recovery
```

### C1 — One-Shot Free Continuation

The correction signal appears once, is consumed and exits active experimental context. Downstream continuation is free.

Evidence object: **endogenous inherited inertia**.

### C2 — Persistent Field Propagation

The same semantic field/signal remains continuously available downstream.

Evidence object: **experiment-maintained persistence**. It must not be described as endogenous inertia.

### C3 — ALR Authority-Localized Recovery

ALR:

```text
locate earliest authority/provenance-violating ancestor n*
  -> compute affected dependency closure
  -> preserve unaffected realized structure
  -> repair the violated authority/provenance condition
  -> create a new revision lineage/hash
  -> reopen/re-execute only the affected subgraph
  -> observe residual / recurrence / re-entry / reconstruction
```

Evidence object: **causally localized structural recovery**.

The two nested contrasts are:

- `C1 vs C2` — endogenous inertia versus persistence maintained by continuous experimental delivery;
- `C2 vs C3` — continuous semantic exposure versus dependency/lineage-aware localized recovery.

Semantic correction content should be matched as closely as possible so the intended treatment difference is structural handling rather than richer information in the ALR arm.

## ALR boundary

ALR means **Authority-Localized Recovery**.

It is a localized structural recovery operator. It is **not** the entire R7 structural-steering theory and is not defined merely by repeated feedback.

The recovery anchor is the earliest source-backed ancestor at which a frozen authority/provenance condition was violated, not simply the first text that looks wrong.

The operator targets the affected dependency closure and preserves unrelated successful structure where evidence permits. It repairs the violated condition rather than prescribing a desired final answer.

Full Rerun and Checkpoint Retry may remain useful secondary engineering baselines for recurrence, preservation and cost, but they do not define the main R7 scientific contrast.

## Evidence and review lifecycle

```text
prepare
-> subject run
-> freeze raw evidence
-> integrity validation
-> deterministic structural derivation
-> export bounded semantic-review packets
-> append independent semantic reviews later
-> freeze paper-level evidence object
```

A subject run does not automatically call a paid evaluator.

The preferred architecture is:

> **immutable evidence core + append-only interpretation layers**

## Historical evidence boundary

Historical subject/reviewer evidence, old contracts, old prepared bundles, exploratory persistent-exposure pilots, structured-orchestration pilots and frozen formal batches remain immutable provenance. They are not silently relabeled to match the current theory.

No historical `NOT_ADJUDICATED` evidence is promoted without a new append-only review object permitted by its freeze contract.
